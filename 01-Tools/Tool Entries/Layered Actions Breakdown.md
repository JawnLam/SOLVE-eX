# Layered Actions Breakdown

**One-line summary:** Recursively ask "How will this be implemented?" 3–5 levels deep until you hit concrete actions.

**When to reach for it:** You have a goal but no plan; need to convert it to executable steps.

---

## Purpose Of This Thinking Tool

The purpose of the "Layered Actions Breakdown" thinking tool is to methodically uncover and organize the specific steps necessary to realize a goal or implement a solution. By consistently probing deeper with the question "How?" at each stage of planning, it ensures that every critical detail is addressed, creating a layered structure of tasks that cumulatively lead to the achievement of the objective. This tool aids planners in developing a thorough, step-by-step strategy that accounts for all aspects of execution, minimizing oversights and maximizing the chances of success.

## Why Use This Thinking Tool

This tool is designed to uncover the exact steps needed to execute a solution effectively. By continually asking "How," it prompts you to explore every layer of action until you have a comprehensive and detailed plan.

## How To Use This Thinking Tool

Employ this tool by persistently questioning the implementation process with "How" to reveal a sequence of detailed actions. It guides planners to meticulously map out each necessary task, ensuring nothing is overlooked for successful execution.

```
|======|===============================================|=========================================================================================================|
| Step |                  Description                  |                                              Instructions                                               |
|======|===============================================|=========================================================================================================|
| 1    | Identify the solution or goal.                | Clearly define what you aim to achieve or implement.                                                    |
| 2    | Determine key milestones or objectives.       | List the main outcomes that will guide you toward your goal or solution.                                |
| 3    | Ask how to accomplish each milestone.         | For each objective, question how it can be achieved. (e.g., "How will we implement A? By doing B.")     |
| 4    | Detail the steps for each 'how'.              | Repeat the questioning for each answer given. (e.g., "How will we implement B? By doing C.")            |
| 5    | Continue asking "how" to elaborate the tasks. | Keep asking "how" until you've listed all tasks needed for each objective, usually three to five times. |
| Note | Address any unachievable 'how'.               | If a task seems impossible, use it as a signal to reassess the overall plan and ensure feasibility.     |
|======|===============================================|=========================================================================================================|
```

## The Actual Thinking Tool

```
|============================================================|===================================================|
|                       Goal/Objective                       |                Implementation Steps               |
|============================================================|===================================================|
| State the Goal or Solution to be implemented               | List key implementation milestones or objectives. |
|                                                            | - Objective #1                                    |
|                                                            | - Objective #2                                    |
|                                                            | - Objective #3                                    |
|                                                            | - Objective #N                                    |
| For each objective or milestone, detail the implementation |                                                   |
| plan by asking "How" multiple times:                       |                                                   |
| - How will Objective #1 be implemented? (A1)               | Define the first action step for Objective #1.    |
| - How will Step A1 be implemented? (B1)                    | Define the next action step following A1.         |
| - How will Step B1 be implemented? (C1)                    | Outline the subsequent step after B1.             |
| - How will Step C1 be implemented? (D1)                    | Determine the follow-up action for C1.            |
| ...                                                        | Repeat the process for each subsequent step.      |
|============================================================|===================================================|
```
