# Blue Ocean / Strategy Canvas

**One-line summary:** A strategic framework — Kim & Mauborgne's — that reframes competition from share-grabbing in existing markets ("red oceans") to creating uncontested market space ("blue oceans"), using the Strategy Canvas to map the industry's competing factors and the Four Actions Framework (Eliminate / Reduce / Raise / Create) to design divergent value curves.

**When to reach for it:** Strategic planning when the industry is commoditized and price-competitive; product / service design seeking to escape feature-arms-race; entering new categories; redefining customer experience; and any context where the question is not "how do we beat the competition?" but "how do we make the competition irrelevant?"

---

## Purpose Of This Thinking Tool

**Blue Ocean Strategy** distinguishes between two competitive contexts:

- **Red Oceans** — existing market spaces with defined boundaries, known competitors, share-of-market warfare. Profits compress as competition intensifies.
- **Blue Oceans** — uncontested market spaces where competition is irrelevant because the market doesn't exist yet (or has been redefined).

The central tool is the **Strategy Canvas:**

- **X-axis** lists the factors industry competitors compete on (e.g., for airlines: price, food, lounge, route choice, frequent-flyer program, schedule, comfort).
- **Y-axis** measures investment / performance level on each factor.
- **Current competitors** trace similar value curves on the canvas — they're competing on the same factors at similar levels.
- **Blue-ocean moves** create a divergent value curve via the **Four Actions Framework:**
  1. **Eliminate** factors the industry takes for granted but customers don't actually value
  2. **Reduce** factors below industry standard
  3. **Raise** factors well above industry standard
  4. **Create** factors the industry has never offered

The non-obvious operational insight is that **value innovation requires both differentiation and low cost.** Standard strategic thinking treats them as trade-offs (differentiate AND charge more, OR commoditize AND compete on price). Blue Ocean argues that elimination of unvalued factors funds the creation of new ones — producing differentiation at low cost.

Classic examples:

- **Cirque du Soleil** — eliminated expensive animals, star performers, and multiple show arenas (cost down); reduced fun-and-humor; raised theme/storyline production; created theatrical experience (sophisticated venue, narrative). Created a "theatrical circus" category outside both circus and theater.
- **Yellow Tail wine** — eliminated wine jargon and aging complexity; reduced wine-quality range; raised easy-drinking approachability; created fun, casual brand. Won a non-wine-drinker market.
- **Nintendo Wii** — eliminated cutting-edge graphics; reduced processor power; raised motion-control novelty; created family/casual gaming category.

A second insight: **the framework is criticized.** Critics note examples are easier to identify retrospectively than prospectively, and that "uncontested" often becomes "contested" once successful. Defenders respond that the framework provides a generative thinking discipline, even if outcomes vary.

A third insight: **the canvas is most powerful as workshop visualization.** Drawing the current industry's value curves and then experimenting with Four-Action moves makes the strategic options visible to a team in ways that text descriptions cannot.

## Why Use This Thinking Tool

Three failure modes the framework prevents:

1. **The "compete harder" trap.** Doubling down on existing competitive factors usually accelerates margin compression. Blue Ocean refocuses on changing the factors.
2. **The "differentiation-OR-low-cost" trade-off assumption.** Conventional wisdom forces a choice; Blue Ocean argues both are achievable through factor restructuring.
3. **The feature-arms-race default.** Adding features is the easy strategic move; eliminating factors is harder but often more powerful.

For strategists, product designers, founders, and anyone seeking to redefine rather than win existing markets, Blue Ocean is generative.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|    1 | Define the industry / product category. What's the current competitive arena?  |
|    2 | List the factors competitors compete on. The dimensions where investment is    |
|      | made. Usually 8-15 factors.                                                       |
|    3 | Plot competitors' value curves on the canvas. Where does each invest? Where    |
|      | do they cluster?                                                                   |
|    4 | Apply the Four Actions Framework: which factors to Eliminate? Reduce? Raise?    |
|      | Create?                                                                            |
|    5 | Draw the proposed blue-ocean value curve. Does it diverge from competitors?     |
|    6 | Test the divergence: focus on key factors (not all), away from competitors,    |
|      | and a compelling tagline (the strategy can be summarized).                       |
|    7 | Validate with customer research. Do non-customers care about the eliminated /  |
|      | created factors? Will they switch?                                                |
|    8 | Translate to product, pricing, channel, and go-to-market plans.                 |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
THE STRATEGY-CANVAS STRUCTURE

   Y-axis: Investment level (Low / Medium / High)
   X-axis: Competing factors

      Y
   High|
       |       *               *
       |     /   \           /
       |    *     *         *
       |   /       \       /
       |  *         *     *
   Low |_/_______________/__________________
       Factor1 Factor2 Factor3 Factor4 ...

   * = competitor's value curve (similar shape across
       competitors in red ocean)

   Blue-ocean curve diverges:
       Lower on some factors (Eliminate / Reduce)
       Higher on some (Raise)
       Includes new factors competitors don't have
       (Create)

THE FOUR ACTIONS FRAMEWORK

   For each factor in the industry:

   ELIMINATE — factors the industry takes for granted
   that customers don't actually value
   (Industry assumes "more is better"; reality: nobody
   cares.)

   REDUCE — factors below industry standard
   (Customers don't need this much.)

   RAISE — factors well above industry standard
   (Where customers are underserved.)

   CREATE — factors the industry has never offered
   (Where customers have unmet needs.)

   ELIMINATE + REDUCE → cost down
   RAISE + CREATE → value up
   Both together → value innovation

THE WORKED EXAMPLE — CIRQUE DU SOLEIL

   Industry: traditional circus
   Factors competitors compete on:
       Animal performances, star performers, multiple
       show arenas, fun and humor, thrills/danger,
       discount price, audience aisles, refreshments

   Cirque's blue-ocean moves:
       ELIMINATE: animal performances, star performers,
       multiple show arenas, audience aisles
       REDUCE: fun-and-humor, thrills/danger, refreshments
       RAISE: unique venue
       CREATE: theme / storyline, artistic music and
       dance, refined experience, sophisticated price
       point

   Result: theatrical circus — new category. Higher
   ticket prices despite cost reductions; new audience
   (adults, corporate, theater-goers) replacing
   declining traditional circus audience.

THE THREE CHARACTERISTICS OF GOOD BLUE-OCEAN STRATEGY

   Kim & Mauborgne's tests:

   1. FOCUS
       Strategy concentrates on the few factors that
       matter most. Doesn't try to be everything.

   2. DIVERGENCE
       Value curve genuinely differs from competitors'.
       If it just shifts the same curve up or down,
       it's not blue ocean.

   3. COMPELLING TAGLINE
       Strategy can be summarized in a clear, memorable
       message. "Cirque du Soleil: theatrical circus."
       "Southwest Airlines: speed of plane, price of
       car." If you can't summarize, the strategy
       isn't clear.

THE NON-CUSTOMER FOCUS

   Blue Ocean strategy targets three tiers of
   non-customers:

   FIRST TIER: "Soon-to-be" non-customers — using your
   industry minimally; ready to leave.

   SECOND TIER: "Refusing" non-customers — consciously
   chose not to use your industry.

   THIRD TIER: "Unexplored" non-customers — never
   considered the industry; in another market entirely.

   These tiers are larger than current customers.
   Asking "what would bring them in?" surfaces the
   factors to eliminate, raise, and create.

   Cirque didn't try to win circus-goers from Ringling;
   it brought in non-circus-goers (theater-goers,
   corporate event planners).

THE COMMON FAILURE MODES

   1. INSUFFICIENT FACTOR LIST
        Only listing 3-4 factors. Recovery: list 8-15;
        granularity reveals options.

   2. NOT REALLY BLUE OCEAN
        Curve shifts but doesn't diverge. Recovery:
        check focus / divergence / tagline tests.

   3. ELIMINATING WHAT CUSTOMERS VALUE
        Cutting too aggressively. Recovery: validate
        with non-customers; some "industry assumptions"
        are valued by some customers.

   4. CREATING FACTORS NOBODY WANTS
        Imagined value vs. real demand. Recovery:
        validate with target non-customers.

   5. RED OCEAN COMING
        Successful blue ocean attracts entrants;
        becomes red over time. Recovery: plan for
        evolution; have next blue-ocean move ready.

   6. BLUE-OCEAN-WASHING
        Calling small differentiation "blue ocean."
        Recovery: apply the three tests strictly.

THE OPERATIONAL TEMPLATE

   Industry / category: ______________________________

   Competing factors (8-15):
       1. _________________________________________
       2. _________________________________________
       3. _________________________________________
       ...

   Competitor value curves (where they cluster on each
   factor):
       _________________________________________________

   Four Actions:
       ELIMINATE: ______________________________________
       REDUCE: ________________________________________
       RAISE: ________________________________________
       CREATE: _______________________________________

   Proposed blue-ocean value curve:
       (sketch divergent curve)

   Three tests:
       Focus on few factors? Y / N
       Divergent from competitors? Y / N
       Compelling tagline? "________________________"

   Non-customer tier targeted: 1 / 2 / 3

   Validation plan: ___________________________________
```

> **Operational notes:** Four disciplines. (1) The Four Actions are the generative engine. Listing factors and adjusting their levels isn't enough; the question is which to eliminate (cost down), which to create (new value). The both-together is the value innovation. (2) Apply the three tests. Many "blue ocean" claims fail focus/divergence/tagline. The tests separate genuine blue-ocean moves from ordinary differentiation. (3) Target non-customers. Existing customers tell you about red-ocean factors; non-customers reveal what would expand the market. The framework is most powerful when used to bring in new audiences, not to win existing ones. (4) Plan for evolution. Today's blue ocean is tomorrow's red ocean as competitors enter. The successful firm has the next move ready before margins compress.
