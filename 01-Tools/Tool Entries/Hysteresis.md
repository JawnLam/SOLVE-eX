# Hysteresis

**One-line summary:** A system's current state depends not just on current inputs but on its history — equilibria are not unique because the path taken matters.

**When to reach for it:** Labor markets after a recession; cultural/institutional reform; ecological systems after disturbance; any system suspected of having multiple stable equilibria.

## Purpose

Hysteresis contradicts the equilibrium-as-unique intuition: where it operates, the system can be in different stable states depending on the path that brought it there. Long-term unemployment, deforestation tipping points, and norm-shifts all show hysteresis. The strategic implication: returning inputs to their original level may not return outputs to their original level. The tool is recognizing hysteretic dynamics and pricing interventions accordingly.

## How To Use

1) Ask: if I reverse the recent change in inputs, will outputs reverse? 2) If no — hysteresis is operative. 3) Identify the historical event that moved the system. 4) For policy, recognize that 'undoing' the originating event won't undo the outcome. 5) Design path-aware interventions instead of state-only ones.
