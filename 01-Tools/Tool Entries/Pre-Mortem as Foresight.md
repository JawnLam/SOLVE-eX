# Pre-Mortem as Foresight Practice

**One-line summary:** A re-framed pre-mortem that asks "what alternative futures does each failure mode produce?" — generating a branching foresight landscape rather than a flat list of risks, so the present-day decisions get assessed against the future-world each one creates.

**When to reach for it:** Strategic decisions where the question is not "will this fail?" but "*how* will the world look depending on which failure mode dominates?"; long-horizon planning where multiple distinct failure modes lead to materially different futures; portfolio decisions where the right move depends on which failure mode is most expensive.

---

## Purpose Of This Thinking Tool

Klein's original pre-mortem (2007) is adversarial: imagine the project has failed catastrophically; work backwards to find what caused the failure. Powerful, but flattens the futures landscape into a single failed scenario.

The non-obvious operational move of *pre-mortem as foresight*: **don't ask "did it fail?" — ask "WHICH failure mode dominated, and what world did each create?"** This separates the failure modes from each other and surfaces the branching futures, each with its own implications for present-day decision.

Example contrast:

- **Adversarial pre-mortem:** "Imagine this AI strategy failed. Why?" → list of risks (technical, market, regulatory, talent).
- **Foresight pre-mortem:** "Imagine two years from now. Trace three distinct futures: (a) technical failure dominated; (b) market shifted; (c) regulatory capture. Describe each world. What does each imply for our present-day choices?" → three branching futures, each requiring different hedges.

A second insight: **the foresight version surfaces present-day decisions that are robust across failure modes** (worth doing regardless of which failure dominates) vs. **decisions whose value depends on which failure happens** (these need explicit prioritization). The adversarial version conflates these because it tracks a single failure path.

A third insight: **the technique is also useful in non-failure framing** — "imagine three alternative successes; what does each world look like; which present-day decisions enable which?" The mechanics are identical; the imagined future is just shifted from failure to success.

## Why Use This Thinking Tool

Three failure modes the practice prevents:

1. **Single-path risk lists.** The standard pre-mortem produces a flat list that misses the future-world differences between risks. Foresight pre-mortem makes those differences explicit.
2. **Decision robustness blindness.** Without separating the futures, it's hard to see which decisions are robust (good across futures) vs. which are bets on a specific future. The branching surfaces the difference.
3. **Optimism bias survival in foresight work.** "Imagine success" tends to anchor on one canonical happy ending. "Imagine three different successes" forces variation.

The framework's empirical case rests on Klein's broader Recognition-Primed Decision research (firefighters, military commanders, ER doctors) showing that branching-mental-simulation outperforms single-path planning under uncertainty.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|  1   | Frame the time horizon and decision context. "It's two years from now. We took  |
|      | the X strategy. Where are we?"                                                  |
|  2   | Generate 3-5 distinct failure modes — not "many ways it failed" but distinct    |
|      | causes that produce different future-worlds. (Technical / market / talent /     |
|      | regulatory / partnership / macro.)                                              |
|  3   | For each failure mode, write the future-world it produces. 2-3 sentences each. |
|      | Vivid, specific, present-tense.                                                 |
|  4   | Cross-impact analysis. For each present-day decision, ask: does this decision  |
|      | help across multiple futures, or only in one?                                   |
|  5   | Identify ROBUST decisions (good in 3+ futures) and BETTING decisions (only      |
|      | good in 1 future).                                                              |
|  6   | Make the present-day plan. Prefer robust decisions; explicitly mark betting    |
|      | decisions as bets and decide whether to take them.                              |
|  7   | Optional: repeat in success framing (3 distinct success modes) for the opposite|
|      | half of the futures landscape.                                                  |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
Foresight Pre-Mortem Sheet

TIME HORIZON:  ___ years
DECISION CONTEXT:  _________________________________

DISTINCT FAILURE MODES (3-5; must produce DIFFERENT future-worlds):

  Mode A: ________________________________________
  Mode B: ________________________________________
  Mode C: ________________________________________
  Mode D: ________________________________________

FUTURE-WORLD UNDER EACH (vivid, specific, present-tense):

  Under A:
  _________________________________________________

  Under B:
  _________________________________________________

  Under C:
  _________________________________________________

  Under D:
  _________________________________________________

CROSS-IMPACT MATRIX:

   Present-day decision        |  Helps under A?  B?  C?  D?
   ________________________    |     ___  ___  ___  ___
   ________________________    |     ___  ___  ___  ___
   ________________________    |     ___  ___  ___  ___
   ________________________    |     ___  ___  ___  ___
   ________________________    |     ___  ___  ___  ___

ROBUST DECISIONS (good in 3+ futures):
   - _____________________________________________
   - _____________________________________________

BETTING DECISIONS (good in only 1 future):
   - _____________ (betting on future ___)
   - _____________ (betting on future ___)
   For each betting decision: is the bet conscious and accepted? [ ]

OPTIONAL — alternate-success pre-mortem (3 distinct successes):

  Success Mode 1: _____________________________________
  Success Mode 2: _____________________________________
  Success Mode 3: _____________________________________

  Which present-day decisions enable each?
  _________________________________________________
```

> **Operational notes:** (1) **Modes must be distinct futures, not multiple causes of the same future.** "Failed because of bug X" and "failed because of bug Y" both lead to "failed product" and don't generate distinct future-worlds. "Failed because the technology underperformed" vs "failed because the market shifted" do produce different worlds. (2) **Resist quick risk listing.** The foresight version is slower than adversarial pre-mortem; the value is in writing the future-worlds vividly, not in cataloging risks fast. (3) **Robust decisions are often boring** (build optionality, hire flexibly, document well) and easy to deprioritize; the technique's main payoff is making the boring decisions visible as high-value rather than dismissed.

## Related Tools and Frameworks

- **Pre-Mortem** (adversarial) — companion tool; this entry is the foresight-side variant.
- **Backcasting / Natural Step Backcasting** — pairs as the future-state-to-present-action method once a target future is selected.
- **Design Fiction** — useful for vividly building one of the foresight pre-mortem's future-worlds.
- **Horizon Explorer** — broader scenario-planning toolkit; pre-mortem-as-foresight is a focused subset.
