# Sleep Hygiene & Cognitive Performance Protocol

**One-line summary:** A behavioral protocol — light exposure, temperature, timing, substance avoidance — that protects sleep architecture (REM, slow-wave, glymphatic) as the upstream input to downstream cognitive performance (memory consolidation, emotional regulation, error correction, learning).

**When to reach for it:** Persistent cognitive degradation that doesn't yield to more effort; emotional reactivity disproportionate to circumstances; learning or creative work that requires consolidation; high-performance contexts (academic, athletic, surgical, executive) where small sleep optimizations have large cognitive payoffs.

---

## Purpose Of This Thinking Tool

Walker's central operational claim: **sleep is not optional cognitive overhead.** REM (rapid-eye-movement) sleep does emotional memory processing; slow-wave sleep does factual consolidation; glymphatic clearance flushes metabolic byproducts (including amyloid-beta) that accumulate during waking. Skipping or fragmenting any of these phases produces measurable downstream cognitive deficits the next day.

The non-obvious operational insight: **sleep duration is necessary but not sufficient.** Eight hours of fragmented or off-cycle sleep produces less cognitive recovery than seven hours of consolidated, well-cycled sleep. The protocol optimizes for *architecture* (the four-stage cycling), not just duration.

Behavioral inputs that affect architecture (with rough magnitude):

- **Light timing.** Morning bright-light exposure (10+ min, ideally outdoor) anchors circadian rhythm. Evening light suppresses melatonin and delays sleep onset.
- **Temperature.** Core temperature must drop ~1°C for sleep onset; cool bedroom (~65°F / 18°C), warm shower 1-2hr before bed (paradoxically helps via post-shower temperature drop).
- **Caffeine.** Half-life ~5-6 hours. Coffee at 2pm = quarter-dose still active at 10pm. Caffeine after noon meaningfully reduces deep sleep even when sleep onset feels unaffected.
- **Alcohol.** Suppresses REM in the second half of the night. Reduces both memory consolidation and emotional regulation the next day even at moderate doses.
- **Timing consistency.** Bedtime variation within ~30 min is more cognitively protective than longer-but-irregular sleep.
- **Wind-down ritual.** 30-60 min of low-arousal activity before bed. Screen-light from devices is real but secondary to content arousal.

A second insight: **the protocol pays compounding cognitive dividends.** A week of optimized sleep produces measurable improvements in working memory, emotional regulation, creative insight tasks (Wagner et al., 2004 — the "Number Reduction Task" famously showed insight rates ~3x higher after sleep), and physical recovery. Walker's argument: there is no single intervention with cognitive ROI comparable to consistently good sleep.

## Why Use This Thinking Tool

Three failure modes the protocol prevents:

1. **Sleep-as-leftover.** Treating sleep as the time remaining after everything else. The protocol re-anchors sleep as upstream input.
2. **Duration-only optimization.** Counting hours without attending to architecture. The protocol optimizes the inputs that produce good architecture.
3. **Performance-cost denial.** Most people underestimate their own cognitive degradation from chronic mild sleep restriction. Self-rated cognitive performance and objective performance diverge after a few nights of restriction.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|  1   | Establish baseline: current sleep duration, consistency, and cognitive marker  |
|      | (e.g., morning subjective alertness 1-10).                                      |
|  2   | Set consistent wake time — 7 days a week. The wake time anchors circadian      |
|      | rhythm; bedtime adjusts to it.                                                  |
|  3   | Morning light exposure within 30-60 min of waking. 10 min outdoor or bright   |
|      | indoor light.                                                                   |
|  4   | Caffeine cutoff: 8-10 hours before bed (typically noon-2pm for a 10pm bedtime).|
|  5   | Bedroom temperature: 65-68°F / 18-20°C. Cool bedroom + warm shower 1-2 hr     |
|      | before bed.                                                                     |
|  6   | Wind-down ritual: 30-60 min low-arousal activity before bed. Same activities  |
|      | each night (signals the circadian system).                                      |
|  7   | Alcohol management: ideally avoided within 3 hours of bed; less is better.   |
|  8   | Weekly review: did cognitive markers shift? Iterate inputs that show effect.   |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
Sleep Protocol Implementation Sheet

WAKE TIME (consistent 7 days/week): _______
TARGET BEDTIME (8h before wake):    _______

MORNING ANCHORS:
   [ ] Bright-light exposure within 30-60 min of waking
   [ ] Brief outdoor walk if possible

DAYTIME INPUTS:
   [ ] Caffeine cutoff time: ____ (8-10 hrs before bed)
   [ ] Avoid napping after 2pm (or limit to 20 min)

EVENING WIND-DOWN (last 60 min):
   [ ] Lights dimmed
   [ ] No new-content / arousing screen content
   [ ] Warm shower if applicable
   [ ] Same wind-down activities each night (reading,
       quiet conversation, etc.)
   [ ] Bedroom temp 65-68°F / 18-20°C

AVOID:
   [ ] Alcohol within 3 hrs of bed
   [ ] Heavy meals within 2 hrs
   [ ] Vigorous exercise within 2 hrs
   [ ] Phone in bed (especially scrolling)

WEEKLY REVIEW:

   Day   |  Bed   |  Wake  |  Quality (1-10) | Morning alertness (1-10)
   Mon   |        |        |                 |
   Tue   |        |        |                 |
   Wed   |        |        |                 |
   Thu   |        |        |                 |
   Fri   |        |        |                 |
   Sat   |        |        |                 |
   Sun   |        |        |                 |

ITERATION: What input changed → what marker shifted?
   _________________________________________________
```

> **Operational notes:** (1) **The single highest-leverage move is consistent wake time.** If only one input changes, this. Anchors everything else. (2) **The protocol is dose-dependent over weeks, not days.** First few nights of improved hygiene may not show benefits as sleep debt unwinds. Two-week trial before assessing. (3) **Sleep tracking is useful but not authoritative.** Subjective measures (morning alertness, mid-afternoon energy, evening cognitive sharpness) often track outcomes better than wearable metrics. (4) **Clinical insomnia is different.** If sleep onset is chronically >30 min or sleep is fragmented despite good hygiene, CBT-I (Cognitive Behavioral Therapy for Insomnia) is the evidence-based treatment, not more hygiene effort.
