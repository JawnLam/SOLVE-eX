# Network Effects

**One-line summary:** A product's value to each user increases as more users join — the underlying mechanism for many platform monopolies and winner-take-most markets.

**When to reach for it:** Evaluating platform/marketplace strategy, network-dependent product launches, anti-trust analysis, defensibility assessment for businesses with users-attract-users dynamics.

## Purpose

Network effects produce winner-take-most dynamics because the value asymmetry between large and small networks compounds over time. The strategic implication: in markets with strong network effects, early-mover scale is decisive; in markets without, the focus shifts to other defensibility sources (brand, switching costs, IP). The tool is recognizing whether a market has the property, distinguishing same-side from cross-side network effects, and locating sources of network-effect erosion (multi-homing, local network effects).

## How To Use

1) Ask: does this product become more valuable per user as more users join? 2) If yes, distinguish same-side (Slack: more colleagues using it) from cross-side (eBay: more buyers attract sellers, vice versa). 3) Identify the underlying mechanism (compatibility, liquidity, social validation). 4) Strategically: race to scale; price for adoption over margin in growth phase. 5) Identify erosion conditions (multi-homing, regulation, technology shifts).
