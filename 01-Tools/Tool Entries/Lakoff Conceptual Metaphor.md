# Lakoff's Conceptual Metaphor

**One-line summary:** A framework for analyzing how abstract concepts (time, argument, ideas, life) are routinely structured by metaphoric mappings from concrete domains — and how these mappings shape what feels natural to think and say.

**When to reach for it:** Strategic communication design, policy framing, marketing positioning, conflict mediation (parties often operate from different conceptual metaphors), and self-audit for limiting frames in one's own thinking.

---

## Purpose Of This Thinking Tool

Lakoff and Johnson's *Metaphors We Live By* (1980) made a striking claim: most abstract thought is organized by *conceptual metaphors* — systematic mappings from concrete experiential domains to abstract ones. We don't just *say* "argument is war" decoratively; we *think* about argument as war, with all its entailments — defensible positions, attacking weak points, winning, losing. The metaphor structures what's salient, what's possible to say, and what counts as success.

The non-obvious operational insight is that conceptual metaphors are *consequential*, not ornamental. ARGUMENT IS WAR makes some moves natural (attack, defend, win) and others invisible (collaborate, build together). LIFE IS A JOURNEY makes "where are you going?" natural; LIFE IS A STORY makes "what's the next chapter?" natural. Different metaphors yield different fluency for different moves.

For political and policy communication, Lakoff's later work demonstrated that frames pre-determine which arguments register; trying to argue against a frame using its own vocabulary often reinforces it ("don't think of an elephant" forces you to think of an elephant). The remedy is to *re-frame* using a different conceptual metaphor — not to negate the existing one.

## Why Use This Thinking Tool

Three failure modes metaphor-awareness prevents:

1. **Frame-as-given.** Metaphors operating in your own thinking are usually invisible. Naming them opens up alternatives.
2. **Talking past each other.** Disagreements often stem from operating within different conceptual metaphors. Naming them is the path through impasse.
3. **Counterproductive negation.** Arguing against a frame within its own vocabulary reinforces the frame. Re-framing requires different vocabulary.

For consulting and communication design, conceptual-metaphor analysis is a strategic activity — identifying the metaphor in play, choosing whether to ride it or reframe, designing language that activates the chosen frame.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|    1 | Listen for the metaphor. Common signals: prepositions (up / down / in / out),   |
|      | concrete-action verbs applied to abstract subjects ("attack", "build",          |
|      | "shake"), idioms.                                                               |
|    2 | Name the source domain (concrete) and target domain (abstract). e.g.,           |
|      | "ARGUMENT (target) IS WAR (source)."                                            |
|    3 | List the entailments — what the metaphor makes natural to say / think.          |
|    4 | List the foreclosed moves — what the metaphor makes hard to think.              |
|    5 | Consider alternative metaphors for the same target. ARGUMENT IS DANCE? IS A     |
|      | JOINT EXPLORATION? Each yields different fluency.                               |
|    6 | Choose deliberately for the situation. If your goal is collaboration, the       |
|      | WAR metaphor is counterproductive; reframe.                                     |
|    7 | Reinforce the chosen frame consistently in language; isolated word choices      |
|      | won't shift cognition, but pervasive framing will.                              |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
COMMON CONCEPTUAL METAPHORS (Lakoff & Johnson catalog)

    ARGUMENT IS WAR        — "indefensible position", "attack the premise",
                              "demolish the argument", "won that one"
    TIME IS MONEY          — "spend / save / waste / budget time"
    IDEAS ARE FOOD         — "food for thought", "half-baked", "swallow that"
    UP IS GOOD / GOOD IS UP — "high quality", "lift our spirits", "down day"
    THEORIES ARE BUILDINGS — "foundation", "framework", "supports", "collapses"
    LIFE IS A JOURNEY      — "where are you headed?", "crossroads", "lost"
    LIFE IS A STORY        — "next chapter", "rewrite", "plot twist"
    RELATIONSHIPS ARE PLANTS — "growing apart", "tending", "rooted"
    THE MIND IS A CONTAINER — "hold a thought", "out of mind", "full of ideas"
    EVENTS ARE ACTIONS     — "the storm devastated the town"
    ORGANIZATIONS ARE PERSONS — "the company decided", "Apple thinks"
    MORE IS UP             — "rising costs", "high prices"
    UNDERSTANDING IS SEEING — "see what you mean", "vision", "blind to"

    Each frames a target by importing structure from the source. Different
    frames make different moves natural.

METAPHOR-AUDIT WORKSHEET

      ___________________________________________________________________

    Words / phrases that recur:
      ___________________________________________________________________

    Conceptual metaphor in play:  __________ IS __________

    What this metaphor makes salient:
      _____________________________________________________________________
      _____________________________________________________________________

    What this metaphor obscures or forecloses:
      _____________________________________________________________________

    Alternative metaphors that would re-frame:
      Alternative 1: __________ IS __________
        What it makes salient: ________________________________________
      Alternative 2: __________ IS __________
        What it makes salient: ________________________________________

    Choice and rationale: ____________________________________________

REFRAME EXAMPLES

      Default: ARGUMENT IS WAR
      Alternative: ARGUMENT IS A JOINT EXPLORATION
        Vocabulary shift: "let's investigate" / "what do we know" /
          "together we can find" — produces collaborative discourse
          where the war frame produces oppositional.

      Default: TIME IS MONEY
      Alternative: TIME IS A RIVER
        Vocabulary shift: "flow" / "drift" / "swim with / against" /
          "deep currents" — supports patience-and-presence framing
          where money frame produces scarcity-and-spending.

      Default: ORGANIZATION IS A MACHINE
      Alternative: ORGANIZATION IS AN ECOSYSTEM
        Vocabulary shift: "thrive" / "habitat" / "diversity" / "balance"
          / "succession" — supports systems-thinking moves where machine
          frame produces engineering-and-fix moves.

DELIBERATE FRAMING IN COMMUNICATION

    When designing strategic language:
      [ ] Identify the metaphor that supports your intended framing
      [ ] Use vocabulary consistent with that metaphor throughout
      [ ] Avoid mixing metaphors (mixed frames produce cognitive friction)
      [ ] Don't negate competing frames in their own vocabulary —
          replace with your frame's vocabulary instead
      [ ] Repeat. Single word choices don't shift cognition; consistent
          framing does.
```

> **Operational notes:** Three disciplines. (1) Don't fight a frame in its own vocabulary. "We're not at war here" still activates WAR. Replace with your frame: "We're working through this together" activates COLLABORATION-AS-CONSTRUCTION. The replacement, not the negation, is the move. (2) Beware mixed metaphors. "Let's attack this challenge by building a robust framework that grows with us" mixes WAR + BUILDING + PLANT. The mixed frame creates cognitive friction; readers register inconsistency. (3) Sustain the chosen frame. A single deliberate word in a sea of default vocabulary makes no impact; pervasive consistent framing changes the cognitive territory. Fourth: in conflict, often what feels like substantive disagreement is metaphor disagreement. Naming this — "you're framing this as X; I'm framing it as Y; let's see what each makes possible" — opens space neither single-frame argument can.
