# EMDR Resource Installation

**One-line summary:** A pre-protocol stabilization technique — installing positive resource states (Calm Place, Inner Wise Figure, Mastery Memory) via bilateral stimulation before trauma processing.

**When to reach for it:** EMDR phase 2 (preparation); pre-trauma-work stabilization for high-affect clients; building resilience resources before reprocessing.

## Purpose

Standard EMDR begins reprocessing in phase 4. For clients with limited affect-regulation capacity or complex trauma, jumping directly to reprocessing can be overwhelming. Resource Installation uses the bilateral-stimulation mechanism in reverse: strengthen positive states before processing negative ones. The technique builds a portable internal resource set (calm place, mastery memory, inner protector) that the client can access between sessions and during processing.

## How To Use

1) Identify the resource (Calm Place, Mastery Memory, Inner Wise Figure). 2) Have the client elaborate the resource imaginally. 3) Add positive cognition and somatic anchor. 4) Apply short sets of bilateral stimulation (slower and shorter than reprocessing). 5) Strengthen until the resource is stable and accessible. 6) Use as resource between sessions and during reprocessing as needed.
