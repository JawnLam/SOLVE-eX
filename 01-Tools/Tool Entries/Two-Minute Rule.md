# Two-Minute Rule

**One-line summary:** If a task takes less than two minutes, do it now — avoids the overhead of capturing, scheduling, and remembering.

**When to reach for it:** Inbox triage; small tasks during work transitions; habit formation (Clear's variant: scale habits down to two-minute starts to overcome activation energy).

## Purpose

Two distinct versions of the rule, both useful. Allen's GTD version: a task taking less than 2 minutes costs more in tracking overhead than in doing — just do it. Clear's habit-formation version: scale a desired habit down to a 2-minute version (do 5 push-ups, read one page) to overcome activation energy and build the underlying behavior pattern. Both versions exploit the cognitive truth that small actions taken now save disproportionate future overhead.

## How To Use

1) During inbox processing or task triage, ask: 'Will this take less than 2 minutes?' 2) If yes, do it immediately. 3) For habit formation: scale the desired behavior down to a 2-minute version that you can do without resistance. 4) Build the 2-minute habit consistently. 5) Once the 2-minute habit is automatic, expand it.
