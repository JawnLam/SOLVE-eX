# Constant Comparative Method

**One-line summary:** Continuously compare each new observation to existing categories — refining categories, surfacing tensions, and driving theoretical sampling.

**When to reach for it:** Qualitative coding; literature synthesis; case-based reasoning; building a typology from a stream of cases.

## Purpose

The analytic move that pairs with Theoretical Saturation: for each new case, compare to the categories already built. If the case fits cleanly, the category is reinforced. If the case strains the category, the category may need to split or its definition tightened. If the case fits nowhere, a new category is candidate. The disciplined comparison both refines the typology and generates the next sampling question (theoretical sampling).

## How To Use

1) Code the first few cases with provisional categories. 2) For each new case, compare against all existing categories. 3) Note where the case fits, where it strains, where it doesn't fit. 4) Adjust categories: split, merge, add, retire. 5) Use category strain to guide next-case sampling. 6) Continue until saturation.
