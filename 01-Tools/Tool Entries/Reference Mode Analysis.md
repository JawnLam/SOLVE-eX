# Reference Mode Analysis (Sterman)

**One-line summary:** Plot the historical and hypothesized future behavior modes of key variables before building a model — anchors the modeling effort in observable phenomena.

**When to reach for it:** System-dynamics modeling kickoff; framing complex problems where the behavior to be explained is fuzzy; aligning a modeling team on what the model must reproduce.

## Purpose

Many modeling projects fail because the modelers and stakeholders are implicitly aiming at different phenomena. Reference Mode Analysis requires the team to plot the observed historical behavior of key variables and to articulate the hypothesized future behavior under different policies. The plots become the explicit modeling targets. The discipline prevents the common 'build a model, then look for what it explains' anti-pattern.

## How To Use

1) Identify the key variables of interest. 2) Plot each variable's historical trajectory. 3) Identify the behavior modes: growth, decline, oscillation, S-curve, overshoot-and-collapse. 4) Articulate hypothesized future behavior under status-quo and alternative policies. 5) Use the reference modes as targets the model must reproduce.
