# Means-Ends Analysis

**One-line summary:** Iteratively reduce the difference between the current state and the goal state — at each step, identify the largest gap and choose an operator that shrinks it.

**When to reach for it:** Structured problem-solving where the goal is well-specified but the path isn't; algorithmic-thinking pedagogy; debugging.

## Purpose

Newell and Simon's cognitive-science contribution: problem-solving can be modeled as iterative difference-reduction. The decomposition: state the current state, state the goal, identify the largest gap, choose an operator (action) that reduces the gap, apply it, repeat from the new state. The method makes explicit what general problem-solvers do implicitly and provides a teachable algorithm.

## How To Use

1) State the current state precisely. 2) State the goal state precisely. 3) Compute the differences between them. 4) Select the largest/most-important difference. 5) Choose an operator (action) that reduces that difference. 6) Apply it; check the new state. 7) Repeat from step 3 with the new state.
