# Effort Justification Meter

**One-line summary:** 10-question rubric scored 1–10 by each team member; averaged scores drive continue/halt/postpone decision.

**When to reach for it:** A project has been running and you suspect it may no longer justify the effort.

---

## Purpose Of This Thinking Tool

The purpose of the "Effort Justification Meter" thinking tool is to provide a structured approach for teams to periodically reassess the value, feasibility, and priority of ongoing projects or tasks. This tool facilitates a critical examination of whether the current work efforts align with the team's goals, resources, and broader strategic objectives.

## Why Use This Thinking Tool

It's wise to regularly question the purpose of your project or task by asking: "What is the reason behind doing this?" Also, frequently evaluate whether to keep going, halt, or delay the work. This tool is particularly useful in ensuring that projects remain aligned with the team's capacities, the organization's strategic direction, and the evolving external environment. By regularly using this tool, teams can avoid continuing efforts that no longer yield sufficient value or that are misaligned with broader goals.

## How To Use This Thinking Tool

```
|======|==================================================================================|
| Step |                                      Action                                      |
|======|==================================================================================|
|    1 | Team Member Questionnaire: Each team member completes a questionnaire to express |
|      | their views on various aspects of the project or task. The questionnaire can be  |
|      | adapted to suit the specific needs of the project, and a rating                  |
|      | scale (typically 1-10) is used for responses.                                    |
|    2 | Collect Responses: Gather the completed questionnaires and systematically input  |
|      | the responses into a structured table. This step ensures that all team members'  |
|      | opinions are considered in the decision-making process.                          |
|    3 | Calculate Average Scores: Utilize a formula to calculate the average score for   |
|      | each question. This step helps in understanding the overall team sentiment       |
|      | regarding each aspect of the project.                                            |
|    4 | Team Discussion: Conduct a meeting to discuss the results of the questionnaire.  |
|      | This discussion should focus on whether the project or task should proceed, be   |
|      | halted, or be postponed based on the collective input from the team.             |
|======|==================================================================================|
```
