# EMDR (Eye Movement Desensitization and Reprocessing)

**One-line summary:** Francine Shapiro's 8-phase trauma protocol using bilateral stimulation (eye movements, tapping, auditory tones) during recall of distressing memory to facilitate reconsolidation. Heavily evidence-based for PTSD.

**When to reach for it:** Treating PTSD and trauma-related dysregulation. Endorsed by WHO and APA as first-line evidence-based treatment for trauma. Used by trained clinicians; not a self-administered protocol.

## Purpose

Trauma memories stay "stuck" — they replay with full somatic intensity rather than integrating as ordinary memories. EMDR's bilateral stimulation appears to facilitate the reconsolidation process by which a traumatic memory is recoded as past rather than present. The mechanism remains debated (working memory hypothesis, REM-sleep analogue, attention bifurcation); the clinical outcomes are robust.

## How To Use

EMDR uses an 8-phase protocol:
1. **History taking** — assess trauma history, prepare treatment plan.
2. **Preparation** — establish safety, teach grounding, build resourcing.
3. **Assessment** — identify a target memory (image, negative belief, positive belief desired, emotion, body sensation, SUDS rating).
4. **Desensitization** — bilateral stimulation while client holds target; track shifts.
5. **Installation** — strengthen positive belief.
6. **Body scan** — clear residual somatic activation.
7. **Closure** — return to safety.
8. **Reevaluation** — at next session, check whether the target is integrated.
