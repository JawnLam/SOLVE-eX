# Design Fiction / Sci-Fi Prototyping

**One-line summary:** A protocol for building "diegetic prototypes" — concrete artifacts (objects, ads, manuals, interfaces) that would exist in a possible future world — to make speculative futures tangible enough to be argued, tested, and iterated.

**When to reach for it:** Long-horizon strategy work where the future is too distant for forecast models; ethics-in-tech discussions that need to leave the abstract; design ideation that wants to escape current product orthodoxy; teaching futures literacy; communicating a strategic bet that depends on imagining a non-obvious end-state.

---

## Purpose Of This Thinking Tool

Bruce Sterling's coinage: **design fiction is "the deliberate use of diegetic prototypes to suspend disbelief about change."** A diegetic prototype is an artifact that exists *within the world of the fiction* — not a model of the artifact, not an essay about the artifact, but the artifact itself (a user manual for a 2055 product, a tweet from a 2040 character, a service blueprint for a 2030 service).

The non-obvious operational claim: **futures become argueable when they're concrete.** Forecasts ("AI will displace knowledge work") generate abstract debate. A diegetic prototype ("here is the actual onboarding email for a 2031 AI-paired analyst job, including their HR welcome packet") forces specific argument: what role does this person have? What were they hired to do? What's the boilerplate language? What's missing from the email that today would seem essential?

The concrete artifact surfaces assumptions that abstract debate keeps hidden. **The artifact is the deliverable, not the argument.**

Common diegetic prototype forms:
- A product user manual from the future
- An advertisement / marketing brochure for a future product or service
- An everyday object (3D-printed, mocked-up) from the future
- A document type (HR policy, legal filing, lab notebook, school report card) from the future
- A short news clip / video from the future
- A character's personal artifact (resume, journal entry, calendar) from the future

A second insight: **the technique benefits from explicit "weak signals" sourcing.** Pull from real near-present trends (patents filed, research papers, regulatory proposals) and extrapolate. Pure speculation tends toward genre cliché (flying cars, robot uprisings); weak-signals-grounded fiction lands closer to plausible.

## Why Use This Thinking Tool

Three failure modes the protocol prevents:

1. **Abstract futures debate.** Talking about "AI's impact" without specifying who, what, when. The diegetic prototype forces specifics.
2. **Genre-cliché extrapolation.** Building "the future" from sci-fi tropes rather than current weak signals. The protocol's weak-signals step grounds the fiction.
3. **Strategic blindness in long-horizon work.** Corporate strategy that assumes the world of 2035 looks like 2025 + faster computers. The artifact-construction exercise surfaces the systemic-change blindspots.

The corporate adoption (Intel Tomorrow Project, Sony Future Lab, Apple's Knowledge Navigator video from 1987 — a foundational diegetic prototype) shows the technique's traction in strategy contexts, not just art-school speculation.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|  1   | Pick a time horizon. 5/10/25/50/100 years. Longer = more design-fictional space; |
|      | shorter = closer to strategic plausibility.                                     |
|  2   | Gather weak signals. Patents recently filed, research preprints, regulatory     |
|      | proposals, demographic shifts, niche subcultures with mainstream signal-      |
|      | potential. Aim for 6-10 signals.                                                |
|  3   | Pick a world-axis. What single change-driver does this scenario amplify?       |
|      | (Climate collapse, abundance economy, biotech revolution, Network State,       |
|      | post-work, surveillance state, AGI...)                                          |
|  4   | Pick a diegetic prototype form. (Manual, ad, object, document, news clip,      |
|      | personal artifact.)                                                             |
|  5   | Build the artifact. Concrete details — names, numbers, dates, design language. |
|      | Resist the urge to explain. The artifact should look like it actually exists   |
|      | in the future world, not like a presentation about that world.                  |
|  6   | Critique the artifact. What questions does it raise? What assumptions become   |
|      | visible only after looking at the concrete? Iterate.                            |
|  7   | Use as the strategic input. The artifact is the conversation-starter for the   |
|      | strategy discussion that follows.                                               |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
Design Fiction Brief

TIME HORIZON:           ___ years from now (target year: ____)

WEAK SIGNALS in current reality (pull from patents / preprints / niche subcultures):
   1. _______________________________________________
   2. _______________________________________________
   3. _______________________________________________
   4. _______________________________________________
   5. _______________________________________________
   6. _______________________________________________

WORLD-AXIS (single dominant change-driver):
   ____________________________________________________

SUPPORTING CHANGES (3-5 second-order effects of the axis):
   - ____________________________________________
   - ____________________________________________
   - ____________________________________________

DIEGETIC PROTOTYPE FORM (pick one):
   [ ] Product user manual / setup guide
   [ ] Advertisement / marketing brochure
   [ ] Everyday object (sketch or 3D-print)
   [ ] Document (HR policy, legal filing, lab notebook,
       school report, government form, news article)
   [ ] Short video / commercial / news clip
   [ ] Character's personal artifact (resume, journal,
       calendar, tweet thread)

THE ARTIFACT (build it; details matter):
   Title / context: __________________________________
   Author / source: __________________________________
   Date in fiction: __________________________________
   Audience in fiction: ______________________________

   [Insert artifact here — written, visual, or hybrid]

CRITIQUE pass — questions the artifact raises:
   - ____________________________________________
   - ____________________________________________
   - ____________________________________________

STRATEGIC IMPLICATIONS (what this means for current decisions):
   - ____________________________________________
   - ____________________________________________
   - ____________________________________________
```

> **Operational notes:** (1) **Resist explanation.** The artifact should not contain explanations of "how things got this way." Real future-world artifacts don't carry that context; the absence of explanation is what makes them feel real. (2) **Detail is the practice.** Don't write "a 2040 advertisement"; write the actual 2040 advertisement with copy, layout, and call-to-action. The specifics surface assumptions. (3) **Designed objects > designed essays.** A 30-minute object-mockup often produces more strategic insight than a 30-page scenario report. (4) **Multiple prototypes from different angles** strengthen the speculation; build 3-5 artifacts from the same world.

## Related Tools and Frameworks

- **Horizon Explorer** — broader scenario-planning framework; design fiction is a sub-method within it.
- **Imagine A Day In This Future** — first-person experiential complement; design fiction gives the world, this gives the embodied perspective.
- **Seven Generations Thinking** — ancestral-time complement; pairs to extend horizon.
- **Backcasting / Natural Step Backcasting** — works from the diegetic prototype backward to current decisions.
