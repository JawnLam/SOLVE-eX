# Eroding Goals (Senge Archetype #5)

**One-line summary:** When performance falls short of goal, the goal is lowered rather than the performance raised — the gap closes, but the standard erodes.

**When to reach for it:** Quality-standard drift; education-standard slippage; budget-target erosion; SLO/SLI drift in software systems; any institution where performance gaps trigger goal-lowering rather than performance-raising.

## Purpose

The archetype operates when there's a feedback loop both from goal-performance gap to performance pressure AND from gap to goal adjustment. If the gap-to-goal-adjustment loop is faster than the gap-to-performance loop, the goal moves toward the performance rather than the performance moving toward the goal. Over time, the goal slides downward. The pattern is the source of slow institutional decline; recognizing it requires asking whether the standard has shifted, not just whether the gap closed.

## How To Use

1) For each closed gap, ask: did performance rise, or did the goal fall? 2) If the latter, the archetype is operative. 3) Lock the goal explicitly; commit to closing gaps via performance only. 4) Build mechanisms that resist goal-erosion (independent governance, external benchmarks, frozen targets). 5) Re-baseline only with explicit justification.
