# Trimming (TRIZ resource consolidation)

**One-line summary:** Systematically redistribute functions so one component performs another's function — eliminating the second component while preserving the function.

**When to reach for it:** Cost-reduction with function preservation; product simplification; eliminating non-essential parts without losing capability.

## Purpose

Trimming is the modern-TRIZ operationalization of 'increasing ideality.' Starting from the Function Analysis graph, identify a component whose function could be performed by another already-present component (or by an environmental resource). Reassign the function; eliminate the now-redundant component. Each successful trim reduces complexity, cost, and weight while preserving the function. The discipline transfers from products to services, processes, and organizations.

## How To Use

1) Build the Function Analysis graph. 2) For each component, ask: could this function be performed by another component already in the system, or by an external resource? 3) If yes, reassign the function. 4) Eliminate the now-redundant component. 5) Verify the function is still adequately performed. 6) Iterate until no further trimming is possible.
