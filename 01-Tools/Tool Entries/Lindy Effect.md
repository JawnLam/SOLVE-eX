# Lindy Effect

**One-line summary:** For non-perishable things, the longer they've already lasted, the longer they're likely to last — durability begets future durability.

**When to reach for it:** Estimating the remaining lifespan of ideas, technologies, institutions, books, methods; evaluating bets on tradition vs. novelty.

## Purpose

The Lindy effect applies to information-class entities (ideas, methods, technologies) and contrasts with the human-mortality intuition where each additional year reduces expected remaining lifespan. For Lindy-class items, observed durability is evidence of underlying robustness; the same durability is then projected forward. The tool calibrates novelty-vs-tradition decisions: methods that have survived centuries probably continue; methods that emerged last year probably won't.

## How To Use

1) Classify the item (perishable vs. Lindy-class). 2) For Lindy-class, observe how long it has already lasted. 3) Project a roughly proportional remaining lifespan. 4) Use this as a weighting factor when betting on durability — old books over new books, time-tested practices over fashionable ones — unless you have strong specific evidence against.
