# TRIZ Contradiction Matrix

**One-line summary:** A 39 x 39 matrix mapping engineering parameter pairs to the most-relevant Inventive Principles for resolving the contradiction between them.

**When to reach for it:** Engineering design where improving one parameter degrades another; structured access to TRIZ's 40 Inventive Principles for non-experts.

## Purpose

Altshuller observed that engineering contradictions (improving X degrades Y) have recurring patterns of solution. He cataloged 40 Inventive Principles and mapped which principles most often resolve each pair of engineering parameters. The Contradiction Matrix provides a lookup: identify the improving and worsening parameters, find the cell, see which Principles to try. The matrix democratizes access to the principles by removing the need to know which principle applies when.

## How To Use

1) State the engineering contradiction. 2) Identify which TRIZ parameter is improving and which is worsening. 3) Look up the matrix cell. 4) Consider the recommended Inventive Principles (usually 2-4). 5) Apply each to the specific situation. 6) Select the most promising.
