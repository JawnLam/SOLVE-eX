# PDCA / Deming Cycle

**One-line summary:** The continuous-improvement cycle — Plan a change, Do the change small-scale, Check the result, Act (standardize or adjust) — iterated repeatedly.

**When to reach for it:** Continuous-improvement work; quality improvement; learning loops in any iterative system; teaching the disciplined-experiment basis of improvement.

## Purpose

PDCA (also called PDSA — Plan-Do-Study-Act) is the foundational continuous-improvement cycle, more general than DMAIC. It treats every improvement as a hypothesis to be tested: plan a change with explicit prediction, do it small-scale, check the result against the prediction, act on what you learned (standardize if successful, adjust if not). The cycle's power is iterative: each turn produces learning that feeds the next. Many improvement methodologies (Lean, Agile, DMAIC variants) are PDCA in different clothing.

## How To Use

1) Plan: identify what to change, predict the result, design how you'll measure it. 2) Do: implement the change on small scale. 3) Check (Study): compare the result to the prediction. 4) Act: if successful, standardize and scale; if not, learn and revise. 5) Iterate — the cycle never ends.
