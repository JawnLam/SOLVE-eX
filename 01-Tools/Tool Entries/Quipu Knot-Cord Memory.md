# Quipu Knot-Cord Memory System

**One-line summary:** Inca knotted-cord device using decimal positional encoding to store numbers, narratives, census, and astronomical record.

**When to reach for it:** Studying material-cognitive technologies that store and retrieve structured information without alphabetic writing — and modeling tactile-spatial knowledge systems.

## Purpose

The quipu integrates several encoding channels simultaneously: knot type (overhand, long, figure-eight) for digit value, vertical position for power-of-ten place, cord color for category, ply direction and attachment type for additional metadata. A single object holds census counts, tax records, royal genealogies, calendrical knowledge, and reportedly narratives. As cognitive technology, it demonstrates how spatial-tactile encoding can rival writing for structured information.

## How To Use

As an active method (in research, education, or knowledge-architecture work): (1) Identify what is to be encoded (categories, hierarchies, quantities). (2) Assign each dimension to an encoding channel — color for category, position for hierarchy level, knot-type for value. (3) Construct the physical or notational object. (4) Train the reader to traverse it tactilely or visually. The deeper cognitive method generalizes: when designing memory or knowledge architectures, ask which dimensions can be made spatial/physical rather than purely linguistic.
