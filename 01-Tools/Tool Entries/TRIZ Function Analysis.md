# Function Analysis / Function-Modeling (TRIZ)

**One-line summary:** Decompose a system into a graph of useful, harmful, insufficient, and excessive functions — diagnose where value is created and destroyed.

**When to reach for it:** Cost-reduction analysis; quality engineering; product redesign; service-design where the function structure is unclear.

## Purpose

Function Analysis models a system as a directed graph: components are nodes, functions are labeled edges. Each function is classified: useful (it serves the main purpose), harmful (it produces undesired effects), insufficient (it serves but inadequately), or excessive (it serves more than needed). The classification surfaces where the system creates value vs. destroys it, and routes attention to the high-leverage interventions: eliminate harmful, amplify useful, strengthen insufficient, trim excessive.

## How To Use

1) List all components. 2) List all functions each component performs. 3) Classify each function (useful/harmful/insufficient/excessive). 4) Visualize as a graph. 5) Identify the highest-leverage modifications — eliminating a harmful function, trimming an excessive one. 6) Redesign accordingly.
