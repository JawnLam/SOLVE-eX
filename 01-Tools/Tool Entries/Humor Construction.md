# Humor Construction (Incongruity-Resolution)

**One-line summary:** A construction protocol for humor based on Koestler's bisociation theory — set up a frame, then force a sudden re-frame to an incompatible-but-resolvable second frame; the cognitive snap between the two is what is felt as humorous.

**When to reach for it:** Writing comedy, copy, or persuasive material that needs lightness; team or speaking contexts where a deliberate humor move would land; analyzing why a joke worked (or didn't); softening hard messages without losing accuracy.

---

## Purpose Of This Thinking Tool

Koestler's *The Act of Creation* (1964) proposed that humor, art-making, and scientific discovery share an underlying cognitive structure he called **bisociation**: connecting two normally unrelated frames of reference in a way that suddenly reveals a compatibility, producing surprise.

For humor specifically, bisociation takes a characteristic shape: **incongruity-resolution**.

1. **Setup** — frame A is activated. The audience builds expectations from frame A.
2. **Twist** — frame B is suddenly forced; the language ambiguity, the surprise reveal, the pulled-back curtain.
3. **Resolution** — both frames are compatible with the setup, just not in the expected way. The audience snaps to the second frame.

The laugh happens at the snap. The pleasure is the cognitive moment of seeing the second frame fit.

Classic example, Henny Youngman: *"Take my wife — please."* Setup: "take my wife" sets up frame A (consider my wife as a hypothetical / example). Twist: "please" forces frame B (literal request to take her away). Both compatible with "take." Snap.

The non-obvious operational insight: **constructive use requires reverse-engineering.** Don't start with the joke; start with two frames that share a hinge-word, hinge-image, or hinge-situation. The frames must be:

- **Both plausible** from the setup.
- **Mutually incongruous** (couldn't both be true in their usual context).
- **Resolvable** (the audience can hold both simultaneously and feel the fit).

A second insight: **status and context matter to whether humor lands.** Self-deprecating bisociations land easier than other-deprecating ones; powerful-speaker-mocking-weak-target is structurally less funny than powerful-speaker-mocking-self or weak-speaker-mocking-powerful.

## Why Use This Thinking Tool

Three failure modes the protocol prevents:

1. **Joke without bisociation.** Many failed jokes are observations or anecdotes without the frame-shift — funny in the writer's head but missing the structural snap. The protocol forces the second frame to be explicit.
2. **Frame B that doesn't actually fit.** Surreal humor can work, but bisociation requires *some* compatibility between frames. Pure non-sequitur lacks the resolution moment and produces confusion rather than laughter.
3. **Punching down.** Bisociations whose targets are vulnerable status-misaligned subjects produce discomfort, not pleasure. The protocol's status check prevents this.

This tool's lineage is academic (Koestler, Attardo) but the working knowledge lives in the writers' room — Reiss (*The Simpsons*), Dikkers (*The Onion*), and comedy-writing pedagogy generally.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|  1   | Identify the subject / context to be humor-served.                              |
|  2   | Brainstorm hinge candidates: words, images, situations with multiple plausible  |
|      | frames. (Pun-words, double-meaning situations, status flips.)                   |
|  3   | For each hinge, generate Frame A (expected reading) and Frame B (twist).        |
|  4   | Test bisociation:                                                               |
|      |   - Are A and B both plausible from the setup?                                  |
|      |   - Are they incongruous (couldn't both apply in usual context)?                |
|      |   - Is the audience able to snap from A to B and feel the fit?                  |
|  5   | Status check: who is the target of the bisociation? If a vulnerable party, the |
|      | humor will discomfort more than amuse. Adjust target.                           |
|  6   | Tighten language. The setup should activate Frame A unambiguously. The twist   |
|      | word should appear late and trigger Frame B economically.                       |
|  7   | Test on someone outside the writing process. Laugh-out-loud at the snap?       |
|      | Slight smile? Polite nod? Iterate.                                              |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
Bisociation Construction Worksheet

SUBJECT / CONTEXT:
   ____________________________________________________________

HINGE candidates (words/images/situations with double frame):
   - ____________________________________________
   - ____________________________________________
   - ____________________________________________

For the chosen hinge:

   FRAME A (expected reading from setup):
   ________________________________________________

   FRAME B (twist — incongruous but compatible):
   ________________________________________________

BISOCIATION TESTS:
   [ ] Both A and B plausible from the setup?         yes / no
   [ ] Are they incongruous (couldn't co-exist in
       usual context)?                                 yes / no
   [ ] Can audience snap from A to B and feel fit?    yes / no

STATUS CHECK:
   Who is the target of the bisociation?
   ____________________________________________________
   Status differential between speaker and target:
   [ ] Self-deprecation (speaker = target)
   [ ] Lateral (peer target)
   [ ] Punch up (weak speaker, powerful target)
   [ ] Punch down (powerful speaker, weak target) ← AVOID
   [ ] Idea / situation target (not a person)

DRAFT:
   Setup line:  ___________________________________
   Twist line:  ___________________________________
   Twist word position: [ ] early [ ] middle [ ] late
                                                       ↑ best

TEST AUDIENCE REACTION:
   [ ] Laugh        [ ] Smile        [ ] Acknowledgment
   [ ] Confusion    [ ] Discomfort

   If confusion → Frame B is too far from Frame A.
   If discomfort → status check failed.
   If laugh/smile → ship it.
```

> **Operational notes:** (1) **Twist word placement matters.** Bisociation lands best when Frame B is revealed late — typically the last word or phrase. Early reveal kills the snap. (2) **Bisociation generalizes beyond verbal humor.** Visual humor (cartoons, sight gags) uses the same frame-A-to-frame-B mechanic on images. Situational humor uses it on context. (3) **Self-deprecation is the safest default for non-comedy professionals** — speakers, writers, presenters. Status differential is automatically below the audience.

## Related Tools and Frameworks

- **"Yes-And" Improvisation Protocol** — the live-construction sibling; works the same bisociation but in real-time with no edit pass.
- **Stuart Brown Play Frame** — the broader play category; humor is one play-form (Joker type).
- **Lateral Thinking (de Bono)** — adjacent ideation tool; useful for generating the hinge candidates in step 2.
- **TRIZ** — also bisociation-flavored (cross-domain transfer), applied to engineering rather than comedy.
