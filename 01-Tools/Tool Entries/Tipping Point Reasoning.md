# Tipping Point Reasoning

**One-line summary:** Social/economic systems often exhibit threshold dynamics — small additional inputs produce no change until a critical mass triggers a phase transition.

**When to reach for it:** Adoption-curve forecasting, social-movement strategy, contagion-style market dynamics, planning interventions in systems where the value of input depends on what other agents are doing.

## Purpose

Many social phenomena (technology adoption, social-norm shifts, runs on banks) exhibit threshold behavior because individual decisions depend on what others are doing. Below the threshold, the system looks stable and unresponsive; above it, dynamics accelerate suddenly. The discipline is identifying threshold systems (vs. linear ones), estimating the threshold, and designing interventions that move the system toward or away from it.

## How To Use

1) Ask: does each agent's choice depend on what other agents are choosing? 2) If yes, threshold dynamics are likely. 3) Estimate the threshold (often via small experiments or historical analogues). 4) Strategically: concentrate effort to cross the threshold rather than spreading thin. 5) Watch for signal events that suggest the system is approaching tipping.
