# Preferential Attachment / Scale-Free Network Reasoning

**One-line summary:** Networks where new nodes preferentially attach to high-degree existing nodes generate power-law degree distributions — 'rich get richer' graph structure.

**When to reach for it:** Web link analysis, citation networks, social media follower-counts, biological networks; understanding why a few nodes have disproportionate connectivity.

## Purpose

Barabási-Albert showed that simple growth + preferential attachment dynamics produce power-law degree distributions. Many real networks (the web, Twitter, citations, protein-interaction networks) have this scale-free structure. Implications: removing high-degree hubs has outsized impact (efficient targeted attacks; vulnerable to hub failure); marketing/seeding strategies should target hubs; understanding rich-get-richer dynamics in social systems.

## How To Use

1) Estimate the degree distribution of the network. 2) Check whether it follows a power law (log-log linear, fat-tailed). 3) If yes, hub structure is operative. 4) Strategically: protect or target hubs depending on goal. 5) For modeling, use BA model parameters to simulate.
