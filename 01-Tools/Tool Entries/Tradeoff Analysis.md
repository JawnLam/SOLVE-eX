# Tradeoff Analysis

**One-line summary:** Make the tradeoffs explicit — every choice gains some attributes and gives up others; the implicit version produces invisible-but-real losses.

**When to reach for it:** Multi-attribute decisions where stakeholders disagree about priorities; design decisions with cost/quality/time triangles; policy decisions with distributional consequences.

## Purpose

Most consequential decisions involve tradeoffs that are felt but not stated. Making them explicit — naming the attributes being traded, naming the rates of substitution — produces decisions that survive scrutiny, surfaces stakeholder priority disagreements early, and prevents the 'we want everything' failure mode. The tool is the disciplined enumeration of what is gained and what is given up at each option.

## How To Use

1) List the attributes that matter (cost, time, quality, risk, alignment, etc.). 2) For each option under consideration, score each attribute. 3) Make rate-of-substitution decisions explicit (how much cost are we willing to pay for one unit of quality?). 4) Choose the option whose tradeoff profile best matches stated priorities. 5) Document the priorities so they can be revisited.
