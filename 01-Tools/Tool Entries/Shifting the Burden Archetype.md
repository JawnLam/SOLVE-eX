# Shifting the Burden (Senge Archetype #2)

**One-line summary:** A quick symptomatic fix substitutes for a slower fundamental fix; the symptomatic fix gains traction, the fundamental capability atrophies.

**When to reach for it:** Recurring problems where the standard fix is applied repeatedly without resolving the underlying issue; addiction dynamics; outsourcing decisions; technology-debt patterns.

## Purpose

Many systems have both a fundamental solution (slow, capability-building) and a symptomatic solution (fast, capability-eroding). Under pressure, the symptomatic solution gets used, which relieves the symptom but leaves the underlying problem unaddressed. Worse, dependence on the symptomatic solution erodes the capability needed for the fundamental solution, deepening the dependence. The diagnostic is recognizing the dual structure; the intervention is investing in the slow fundamental fix even while the fast symptomatic fix is providing relief.

## How To Use

1) Identify the problem symptom. 2) Identify both candidate solutions: fundamental (slow, addresses root) and symptomatic (fast, relieves symptom). 3) Notice which is being used repeatedly. 4) If symptomatic is dominant, the system is in the archetype. 5) Invest in fundamental even at cost to short-term symptom relief. 6) Reduce symptomatic-solution capacity gradually.
