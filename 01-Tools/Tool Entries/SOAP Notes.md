# SOAP Notes

**One-line summary:** SOAP — Subjective, Objective, Assessment, Plan — is a four-section structure for clinical encounter documentation that doubles as a cognitive scaffold for problem-oriented clinical reasoning.

**When to reach for it:** Any clinical encounter that requires structured documentation, or as a teaching scaffold for novices learning to separate observation from inference.

## Purpose

Larry Weed (1968) introduced SOAP as the cognitive framework for problem-oriented medical records. It forces clinicians to separate patient-reported symptoms (S), observed findings (O), synthesized impression (A), and proposed action (P) — preventing the common error of jumping straight from history to plan without an explicit Assessment step. The structure underwrites both the chart and the thinking.

## How To Use

1. **Subjective** — Record what the patient reports: chief complaint, HPI, ROS, meds, allergies. Patient's words.
2. **Objective** — Record observable findings: vitals, exam, labs, imaging. No inference.
3. **Assessment** — Synthesize S+O into a problem list with prioritized differentials. The cognitive heart of the note.
4. **Plan** — For each Assessment item: diagnostic next steps, therapeutic next steps, patient education, follow-up.
