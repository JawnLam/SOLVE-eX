# Force Field Analysis

**One-line summary:** For any change, list driving forces (push toward) and restraining forces (push against), weight each, and target the restraining forces.

**When to reach for it:** A change is stalled or anticipated to stall — adoption of a new system, behavior change, organizational restructuring, policy shift. You suspect there's a force keeping things stuck even though "everyone agrees" the change is right.

---

## Purpose Of This Thinking Tool

Force Field Analysis comes from Kurt Lewin's field theory: any system holds its current state because driving and restraining forces are in equilibrium. Change isn't about adding effort; it's about shifting the balance. The tool makes both sets of forces visible on a single page so that the levers for change become inspectable instead of invisible.

The non-obvious move Lewin introduced: when you want change, **weakening restraining forces is usually more durable than amplifying driving forces.** Pushing harder raises overall tension in the system and often triggers compensating resistance. Removing a restraint lets the existing drive carry the change with less friction.

This is the signature insight of the tool. Most leaders intuitively reach for the driving-force lever (more incentives, more communication, more pressure) when the higher-leverage move is the restraining-force lever (remove the policy, fix the tooling, address the fear).

## Why Use This Thinking Tool

The tool is especially useful when:

1. **A change is "obviously good" but isn't happening.** The question becomes: what restraining force are we missing?
2. **You're choosing between intervention strategies.** Listing forces forces a comparison of effort vs. expected shift.
3. **You need to communicate why a change is hard.** A picture of the force field is harder to dismiss than abstract concerns.
4. **You're modeling resistance rather than dismissing it.** Restraining forces are usually rational from the perspective of those holding them. Naming them respectfully is the first step in resolving them.

It complements the Power-Interest Grid: where the grid asks *who matters*, Force Field asks *what's blocking*. The two tools combined cover the political and structural dimensions of change.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|    1 | Define the change — a specific desired state, not a vague direction.            |
|    2 | List all driving forces (anything pushing toward the change). Be exhaustive.    |
|    3 | List all restraining forces (anything pushing against). Include fears, habits,  |
|      | structural barriers, prior commitments, sunk costs, and rational objections.    |
|    4 | Score each force 1–5 for strength (or use the scoring method below).            |
|    5 | Sum each side. Note the balance. If restraining ≥ driving, the change won't     |
|      | happen without intervention.                                                     |
|    6 | Identify the 2–3 highest-leverage interventions — usually weakening restraining |
|      | forces, occasionally amplifying driving forces.                                  |
|    7 | For each intervention, name the action, owner, and expected force shift.        |
|======|=================================================================================|
```

> **Scoring tip:** Use 1 (negligible) to 5 (decisive). If you're tempted to use 6+, the force is structural and probably needs to be a separate change initiative. If totals end up close (within 2 points), the change is unstable — small events will push it either way, which means active management matters more than a single big intervention.

> **Restraining-force respect:** Most restraining forces look "irrational" until you understand them. "People resist change" is not an analysis; it's a refusal to do the analysis. Push to name the *specific* restraint: a person's lost status, a team's broken workflow, a prior bet that hasn't paid off, a learned association from a past failure. Specific restraints are addressable; "resistance" is not.
