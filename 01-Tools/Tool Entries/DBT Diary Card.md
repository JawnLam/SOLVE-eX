# DBT Diary Card

**One-line summary:** Daily self-monitoring artifact from Marsha Linehan's Dialectical Behavior Therapy. Tracks urges to self-harm or substance use, prescribed behaviors, emotion intensity, and skills used. Becomes the data substrate for weekly therapy.

**When to reach for it:** In DBT treatment, especially for clients with borderline personality features, self-harm urges, or chronic emotion dysregulation. Adaptable as a self-monitoring tool for anyone wanting structured emotional self-tracking.

## Purpose

Self-report retrospectively at session time is unreliable — emotional intensity collapses, behavior is misremembered, skill-use is forgotten. The diary card captures it daily, in small structured slots. Over weeks the card surfaces patterns invisible to memory: when urges peak, which skills work for which states, which triggers recur. The card *is* the data; sessions interpret it.

## How To Use

1. **Daily entry** — At end of each day (5-10 min), fill in:
   - Urges (0-5) for self-harm, substance use, suicide, target behaviors.
   - Emotions experienced (sad/angry/afraid/shame/joy etc.) with intensity 0-5.
   - Skills used (which of the DBT skills toolkit was deployed).
   - Prescribed behaviors completed (medication, sleep, food).
2. **Bring to weekly session** — Therapist reviews card first; patterns drive session agenda.
3. **Adjust as patterns emerge** — Therapist and client refine which behaviors and skills are worth tracking.
