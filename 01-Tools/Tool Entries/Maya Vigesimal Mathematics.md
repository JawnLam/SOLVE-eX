# Maya Vigesimal Mathematical Reasoning

**One-line summary:** Pre-Columbian base-20 positional number system with explicit zero, used in calendrical and astronomical computation centuries before Hindu-Arabic zero.

**When to reach for it:** Studying mathematical cognition across civilizations, teaching positional notation through cross-cultural comparison, or modeling how an alternative number-base shapes computational thinking.

## Purpose

Maya mathematics used base-20 (vigesimal) positional notation with three symbols: dot (1), bar (5), and a shell/conch glyph (zero). Place values ascend vertically (units, twenties, four hundreds, eight thousands…). Zero functioned both as placeholder and as concept — used in inscriptions long before its introduction to European arithmetic via the Hindu-Arabic system. Used for elaborate calendrical computation (Long Count) and astronomical record (Venus tables, eclipse cycles). Demonstrates that positional notation and zero are not unique to one cultural lineage.

## How To Use

As a teaching/cognitive method: learn the three symbols. Practice writing numbers 0-19 horizontally, then larger numbers stacked vertically. Add and subtract by manipulating dots and bars and carrying between place-values. The base-20 system maps naturally onto fingers-plus-toes counting; observe how a different base reshapes mental arithmetic. Beyond pedagogy, the broader cognitive method: any structured-symbolic representation system shapes what is easy or hard to think — explore alternatives to your default notation when stuck.
