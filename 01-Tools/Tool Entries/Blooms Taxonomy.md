# Bloom's Taxonomy

**One-line summary:** A hierarchical classification of cognitive learning objectives — from Remember (low) through Understand, Apply, Analyze, Evaluate, Create (high).

**When to reach for it:** Curriculum design, assessment design, learning-objective specification; ensuring that instruction targets the right cognitive level; evaluating whether tests measure high-level vs. just recall.

## Purpose

Bloom and colleagues developed the taxonomy to give educators a vocabulary for distinguishing levels of cognitive complexity. The 2001 revision changed the levels to verbs and re-ordered the top two. The taxonomy lets curriculum designers specify objectives precisely: 'students will analyze' is a different target from 'students will recall.' Assessment can then be aligned with target level. Critics note that creativity and other complex cognition don't fit cleanly; defenders use the taxonomy as a useful first cut.

## How To Use

1) For each learning objective, identify the target cognitive level (Remember / Understand / Apply / Analyze / Evaluate / Create). 2) Design instruction appropriate to that level. 3) Design assessments that measure that level — multiple-choice often tests Remember; essays can test Analyze and above. 4) Review the curriculum: is there a healthy mix across levels, or over-concentration on Remember?
