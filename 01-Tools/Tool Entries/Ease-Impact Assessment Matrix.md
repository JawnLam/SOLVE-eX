# Ease-Impact Assessment Matrix

**One-line summary:** 3×3 grid: difficulty × impact; chase the "9s" (high impact, easy to implement).

**When to reach for it:** Many options on the table; need fast triage by visible value.

---

## Purpose Of This Thinking Tool

The purpose of the "Ease-Impact Assessment Matrix" is to provide a quick and efficient way to evaluate and prioritize ideas or alternatives based on two critical factors: their impact and the ease of implementation. This thinking tool is especially valuable in scenarios where decision-makers need to focus on options that will have a significant effect while being feasible to execute. The tool's functionality can be broken down as follows:

1. **Idea Organization:** It starts with listing out all potential ideas or alternatives, encouraging a comprehensive view of available options.
2. **Impact and Ease Scoring:** Each idea is scored on a scale from 1 to 9, with higher scores indicating high impact and ease of implementation. This scoring system helps in objectively assessing the potential value and practicality of each idea.
3. **Visual Prioritization:** By plotting these ideas on a matrix, the tool visually distinguishes between high-value, easy-to-implement options and those that are less feasible or impactful. This aids in quickly identifying the "low hanging fruit" — ideas that offer the greatest impact with the least implementation challenges.
4. **Strategic Focus:** The matrix assists in directing resources and efforts towards ideas that are most likely to succeed and provide significant benefits, ensuring efficient use of time and resources.
5. **Action Planning:** Following the assessment, it provides a framework to develop actionable plans for the top-prioritized ideas, thereby facilitating their practical implementation.

In essence, the "Ease-Impact Assessment Matrix" is an indispensable tool for strategic decision-making, allowing teams and leaders to identify and act on the most promising and practical ideas swiftly.

## Why Use This Thinking Tool

This template is created for a fast and straightforward method to rank options that are both easy to implement and offer significant impact.

## How To Use This Thinking Tool

```
|======|=================================================|
| Step |                   Description                   |
|======|=================================================|
|    1 | List alternatives on a separate sheet with a    |
|      | one or two-word name.                           |
|    2 | Assign a score to each alternative:             |
|      | - 1 for low impact and difficult to implement.  |
|      | - 9 for high impact and easy to implement.      |
|    3 | Use the matrix to identify priorities:          |
|      | - Ideas close to a score of 9 are high-impact   |
|      | and easily implementable ("low hanging fruit"). |
|======|=================================================|
```

```
|==================================|========|========|========|
|       Difficulty / Impact        |  Low   | Medium |  High  |
|                                  | Impact | Impact | Impact |
|==================================|========|========|========|
| Difficult to implement           |      1 |      2 |      3 |
| Moderate difficulty to implement |      4 |      5 |      6 |
| Easy to implement                |      7 |      8 |      9 |
|==================================|========|========|========|
```
