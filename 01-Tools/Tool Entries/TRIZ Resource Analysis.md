# Resource Analysis (TRIZ)

**One-line summary:** Inventory the available substances, fields, time, space, information, and energy at the problem location — looking for free or under-used resources.

**When to reach for it:** Early ARIZ stage; whenever a design seems to require additional inputs but the constraint set forbids them; resource-constrained engineering.

## Purpose

Many engineering problems feel constrained because the conventional framing under-counts the resources present. TRIZ Resource Analysis is a systematic inventory: list every substance and field in the system and its surrounding environment; list time resources (any moment when the system isn't fully busy is a resource); space resources (any unused volume); information resources; energy. The inventory typically reveals usable resources that conventional thinking has overlooked.

## How To Use

1) Draw the system + environment. 2) List all substances present (parts, materials, fluids, air, dust). 3) List all fields (mechanical, thermal, electromagnetic, gravitational). 4) List time resources (idle periods). 5) List space resources (unused volumes). 6) Energy and information. 7) Match resources to system needs.
