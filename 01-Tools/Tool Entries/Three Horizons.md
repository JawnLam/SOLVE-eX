# Three Horizons (Sharpe)

**One-line summary:** Workshop framework mapping three concurrent worldviews — H1 dominant-system, H2 transition zone, H3 emerging future-fit pattern — and the disruptions/innovations bridging them.

**When to reach for it:** Systems-transformation strategy work — when an organization or community senses that the current paradigm (H1) is fitness-declining and a new paradigm (H3) needs cultivating, but the transition (H2) is messy and undetermined. Used heavily in sustainability, regenerative agriculture, civic innovation.

## Purpose

Strategic planning typically extrapolates the current paradigm forward. Three Horizons assumes paradigm shift: H1 is what's currently dominant and will decline; H3 is the emerging fit-for-future pattern; H2 is the messy in-between where contested experiments compete. The framework's value is in distinguishing H2- (innovations that prop up H1 — incrementalism) from H2+ (innovations that bootstrap H3 — pathways to transformation). Strategy is then about resourcing H2+ work.

## How To Use

1. **H1 — Current** — Map the current system: what's working, what's declining, what's increasingly unfit?
2. **H3 — Aspirational** — Articulate the future-fit pattern: what's emerging that, if it succeeded, would replace H1?
3. **H2 — Transition** — Map the experiments and innovations happening between H1 and H3.
4. **Distinguish H2- from H2+** — Which transitions extend H1's life vs bootstrap H3?
5. **Strategic implications** — Where does the organization invest? Defend H1, navigate H2, or seed H3?
