# Collective Objective Builder

**One-line summary:** Structured group + individual reflections to develop a goal that resonates with personal aspirations and group objectives.

**When to reach for it:** Team needs alignment on a goal and individual buy-in matters for execution.

---

## Purpose Of This Thinking Tool

The purpose of the "Collective Objective Builder" thinking tool is to facilitate the creation of a shared goal or understanding within a team or group, especially for a specific topic, project, or issue. This tool is particularly effective in aligning individual members' motivations and objectives with the broader goals of the group or organization, ensuring a unified approach towards achieving a common outcome.

Key aspects:

1. **Collaborative Goal Setting:** The tool encourages group discussions where all team members contribute to defining the main topic or issue and then collectively establish a goal or shared understanding.
2. **Individual and Group Alignment:** By allowing individual team members to reflect on their personal reasons and benefits for resolving the issue, and then aligning these with the group's objectives, the tool ensures that personal and team goals are synchronized.
3. **Inclusive Decision Making:** The process is inclusive, taking into account various perspectives within the team.
4. **Dynamic Goal Refinement:** The tool provides a structure for ongoing evaluation and adjustment of both individual and group goals.
5. **Strategic Alignment with Broader Objectives:** Links the team's goal with the broader organizational mission and vision.
6. **Open Dialogue and Consensus Building:** Emphasizes realistic alignment over absolute agreement.

## Why Use This Thinking Tool

This method is designed to create a shared goal or understanding within a group for a particular topic, project, or problem. It helps align individual motivations with the group's objectives, ensuring that everyone works towards the same outcome.

## How To Use This Thinking Tool

The process involves a combination of group discussions and individual reflections to develop a goal that resonates with both personal aspirations and group objectives. The aim is to achieve alignment, if not complete agreement, between individual and team goals.

```
|=======|==================|=================================================================|
|  Step | Group/Individual |                              Action                             |
|=======|==================|=================================================================|
| 1     | Group            | Define the topic, project, or problem for which you want to     |
|       |                  | establish a goal or shared understanding.                       |
| 2     | Group            | List and agree on the key reasons for resolving this situation. |
| 3     | Individual       | Each member identifies their personal reasons and benefits for  |
|       |                  | resolving the situation.                                        |
| 4     | Group            | Craft a goal statement starting with "How can..." or "How to…"  |
| 5     | Group            | Discuss whether the goal contributes to broader org goals.      |
| 6     | Individual       | Each member assesses whether personal goals align with team.    |
| 7     | Group            | Strive for alignment (not necessarily agreement). Use consensus |
|       |                  | building or composition changes if vast differences.            |
| 8     | Group            | Finalize and write the team goal statement.                     |
|=======|==================|=================================================================|
```

> The process emphasizes realistic alignment over absolute agreement. Where alignment isn't feasible, consider consensus-building strategies or changes in group composition.
