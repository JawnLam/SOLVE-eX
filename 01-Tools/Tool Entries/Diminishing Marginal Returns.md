# Diminishing Marginal Returns

**One-line summary:** Beyond an inflection point, each additional unit of input produces less additional output than the previous unit — concavity in the input-output relationship.

**When to reach for it:** Resource-allocation decisions, scaling decisions, fertilizer/medication dosing analogies; any context where adding more might not produce proportional gain.

## Purpose

Most production and effort functions exhibit diminishing returns past some threshold. The strategic implication: optimal allocation does NOT pour all resources into the highest-current-yield activity; instead, it spreads across activities until marginal returns equalize. The tool corrects the naive 'best activity gets everything' allocation, which over-invests in one area while under-investing in higher-marginal-return alternatives.

## How To Use

1) Estimate the input-output curve for each activity. 2) Identify the marginal return at current input levels. 3) Reallocate from low-marginal-return to high-marginal-return activities until marginal returns equalize. 4) Re-check periodically — the curves shift.
