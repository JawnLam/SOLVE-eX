# DMAIC Cycle (Six Sigma)

**One-line summary:** The Six Sigma improvement cycle — Define (problem and customer), Measure (current state), Analyze (root cause), Improve (test changes), Control (sustain gains).

**When to reach for it:** Process-improvement projects in Six Sigma organizations; structured root-cause-and-fix work in any context; teaching disciplined improvement methodology.

## Purpose

DMAIC is Six Sigma's canonical improvement workflow. Each stage has specific tools and outputs: Define produces the project charter and customer requirements; Measure baselines current performance; Analyze identifies root causes (often using statistical tools); Improve designs and pilots changes; Control sustains the gains through monitoring. The discipline ensures improvement projects deliver verified, sustained gains rather than transient surface fixes.

## How To Use

1) Define: problem statement, customer requirements, project scope. 2) Measure: baseline current process performance. 3) Analyze: identify root causes using fishbone, Pareto, statistical analysis. 4) Improve: design changes, pilot, validate. 5) Control: establish monitoring, document procedures, transition to operations.
