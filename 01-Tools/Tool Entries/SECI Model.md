# SECI Model (Nonaka & Takeuchi)

**One-line summary:** A four-mode framework — Socialization (tacit→tacit), Externalization (tacit→explicit), Combination (explicit→explicit), Internalization (explicit→tacit) — for diagnosing and designing how organizations convert between tacit and explicit knowledge.

**When to reach for it:** Knowledge management systems that have become document-graveyards because they only operate in Combination mode; onboarding design where tacit expertise transfer is the bottleneck; expert succession in fields with deep tacit components (surgery, manufacturing, law, design); organizations whose knowledge dies when senior people leave.

---

## Purpose Of This Thinking Tool

Polanyi's foundational distinction (1966): **tacit knowledge** is what you know but cannot fully articulate (riding a bike, recognizing a face, making a good edit). **Explicit knowledge** is what you can write down (procedures, formulas, descriptions). Polanyi: "we can know more than we can tell."

Nonaka & Takeuchi's contribution: **organizations create knowledge by cycling through four conversion modes**, not by managing explicit knowledge alone.

The four modes (a 2x2):

|  From \\ To  | **Tacit (output)** | **Explicit (output)** |
|---|---|---|
| **Tacit (input)** | **Socialization** — shared experience, apprenticeship, observation | **Externalization** — analogy, metaphor, articulation |
| **Explicit (input)** | **Internalization** — practice, embodiment, "learning by doing" | **Combination** — synthesis of documents, formal systems |

The non-obvious operational insight: **most KM systems only operate in Combination.** Documents are written, organized, searched, combined — but the system never engages the tacit↔explicit transitions. Tacit knowledge stays trapped in the heads of experts; new hires read documents but cannot internalize them without practice; valuable tacit insights are never externalized.

A second insight: **knowledge creation is a cycle, not a flow.** Tacit → tacit (apprenticeship) → tacit → explicit (articulation) → explicit → explicit (synthesis) → explicit → tacit (practice). Each pass through the cycle adds organizational knowledge. Skipping a mode breaks the cycle.

A third insight: **Externalization is the rarest and most underrated mode.** The move from "I know how to do this" to "here's a metaphor / model / framework for what I know" is what creates organizational knowledge from individual expertise. Most expert know-how is never externalized — and dies when the expert leaves.

## Why Use This Thinking Tool

Three failure modes the model prevents:

1. **Document-graveyard KM.** Systems that operate only in Combination mode. The model diagnoses the missing modes.
2. **Apprenticeship-only knowledge transfer.** Operating only in Socialization mode — knowledge stays trapped in experts, doesn't externalize, doesn't scale.
3. **Read-the-manual onboarding.** Operating only in Internalization mode without preceding Externalization — new hires read but can't translate into practice because the explicit knowledge was never well-externalized.

The framework's adoption is widespread in knowledge management, organizational learning, design firms, and educational institutions. Critiques exist (cultural-specificity to Japanese organizations, oversimplification of tacit/explicit boundary) but the framework's diagnostic value endures.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|  1   | Identify a knowledge-creation challenge in the organization.                    |
|  2   | Diagnose: which modes are currently active? Which are missing or weak?         |
|      |   - Socialization: are people working alongside experts?                        |
|      |   - Externalization: are experts articulating their tacit know-how?            |
|      |   - Combination: are documents being synthesized and connected?                |
|      |   - Internalization: are people practicing what's documented?                   |
|  3   | Design interventions for the missing modes. Each mode has different formats:   |
|      |   - Socialization: pair-working, shadowing, communities of practice            |
|      |   - Externalization: metaphor workshops, narrative interviews, model-building   |
|      |   - Combination: synthesis projects, integration documents, taxonomy building  |
|      |   - Internalization: deliberate practice, simulation, immersion                 |
|  4   | Engineer cycles. The knowledge creation flow is T→T→E→E→T (back to start with |
|      | richer tacit). Design events that move through multiple modes in sequence.     |
|  5   | Re-diagnose periodically. The bottleneck mode shifts as the organization      |
|      | matures.                                                                          |
|======|=================================================================================|
```


> **Operational notes:** (1) **Externalization is the limiting reagent.** Most organizations have plenty of tacit experts and plenty of documents; what they lack is the bridge between them. (2) **Externalization is hard for experts.** Senior experts often *cannot* fully articulate what they know — Polanyi's point. Tools (narrative interviews, metaphor elicitation, dual-protocol "do it and describe it" sessions) help. (3) **The model is cultural.** Nonaka & Takeuchi's framework was developed in Japanese organizations and reflects certain assumptions about apprenticeship and collective work. Use in Western contexts often requires translating the Socialization step deliberately rather than assuming it.
