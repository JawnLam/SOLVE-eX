# Impact-Focused Problem Approach

**One-line summary:** Decompose problem; assign impact value to each part; tackle highest-impact part first; iterate.

**When to reach for it:** A problem feels overwhelming; need to start somewhere with maximum visible progress.

---

## Purpose Of This Thinking Tool

The "Impact-Focused Problem Approach" is a strategic thinking tool designed to simplify and effectively tackle complex problems, both in personal and professional contexts. Its core principle is breaking down a large problem into smaller, more manageable segments, focusing initially on the aspects that have the greatest impact. This methodical approach not only makes daunting issues more approachable but also ensures that efforts are concentrated where they are most needed, leading to more efficient problem-solving.

## Why Use This Thinking Tool

This thinking tool is effective for tackling problems in any area of your life, whether personal or professional. It's based on the concept of starting with the simplest part of a problem. This approach helps in managing complex issues by breaking them down into smaller, manageable parts. It's also useful for implementing projects in a step-by-step manner. This thinking tool simplifies problem-solving by focusing on tackling the problem bit by bit, starting with the most impactful parts. It's designed to prevent wasting effort on the wrong issues and ensures you're addressing the right problem. It also helps in realizing the amount of control or responsibility you have over the problem, encouraging a step-by-step approach to find a solution.

## How To Use This Thinking Tool

Start by addressing the most impactful part of the problem. This initial step, even if major, creates momentum and builds confidence. Then, continue to address the problem one step at a time. This gradual approach allows you to systematically work through the entire problem, making what might seem overwhelming more manageable while ensuring that the problem is resolved in a way that is durable.

```
|======|===================================|===============================================================================================================================|
| Step |              Activity             |                                                  Description                                                                |
|======|===================================|===============================================================================================================================|
|    1 | Identify the Problem              | Start by clearly defining and understanding the problem at hand.                                                              |
|    2 | Validate the Problem              | Ensure you are addressing the correct problem. Use different thinking tools to confirm this.                                  |
|    3 | Set a Goal                        | Write a statement describing the desired outcome once the problem is resolved. Repeat asking the purpose to refine this goal. |
|    4 | Assess Responsibility and Control | Determine if you have the responsibility or control to solve the problem. If not, identify who does.                          |
|    5 | Assign an Impact Value            | Identify and write down the simplest aspect of the problem that has the most impact and tackle that first.                    |
|    6 | Record Completion                 | Decide what action you will take and note the date you completed it ("Did It" Date).                                          |
|    7 | Address the Next Part             | After solving the most impactful part, identify the next part of the problem and address it.                                  |
|    8 | Repeat the Process                | Continue repeating the process, tackling the problem in incremental steps until it is fully resolved.                         |
|======|===================================|===============================================================================================================================|
```

This table serves as a working document where users can articulate the problem, set a goal for its resolution, and then methodically break down the problem into smaller aspects.
