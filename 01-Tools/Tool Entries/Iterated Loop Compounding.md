# Iterated Loop Compounding

**Also known as:** The recursive prescription stance; cycle-over-cycle compounding

**One-line summary:** A stance entered to make every current ADAPT cycle answer to the iterated history of previous cycles and to the conditions of cycles yet to come — recognizing that strategic life is the iterated running of the loop, that each cycle's outcome feeds the next cycle's resource portfolio and interest framing, and that the discipline of running each cycle well is what makes long-horizon compounding possible.

**When to reach for it:** At the start of any session where the user is returning to a strategic situation they have worked on before (a multi-cycle initiative, an ongoing political effort, an iterated career decision); when a decision in front of the user is structurally the same shape as decisions they have made before and the question is whether to repeat the prior approach; when an actor is at a career or organizational inflection point and the question of "what does the next few years look like if I keep running this loop?" needs to be answered; when reviewing past strategic work to ask whether the cycle-over-cycle compounding has been positive or negative.

## Purpose Of This Thinking Tool

**Iterated Loop Compounding** is the stance the ADAPT Loop's recursive prescription requires (Lam 2020 p. 226):

> "Control the resources that facilitate the ability and opportunity to control more resources."

The framework's organizing principle is not that any one cycle is decisive; it is that strategic life is the iterated running of cycles, and the resources, learnings, and positioning that each cycle produces become the starting condition for the next. The field manual's closing note (Field Manual p. 40):

> "Frameworks of this kind — closed-loop, multi-stage, with feedback — are not blueprints. They do not tell you what to do. They describe a structure within which deliberate action is more legible than it would otherwise be. The claim of The ADAPT Loop is not that running this loop makes you correct; it is that running this loop makes your mistakes legible to you afterward, which is what permits a next cycle to be better than the last. To adapt — sustained competence over many cycles — is, in the framework's view, the highest form of strategic skill, and the only kind that compounds."

The non-obvious operational property: **two feedback loops carry information from one cycle into the next** (Field Manual p. 19). The **resource loop** updates the actor's spendable capital — winners gain resources, losers spend them, and both start the next cycle with a different balance than they had this time. The **learning loop** updates the actor's interests — what the actor observed about the world reshapes what the actor will care about next time. Both loops are slow and easily corrupted. The resource loop is corrupted when an actor refuses to acknowledge a depleted balance; the learning loop is corrupted when an actor's observation node is starved, distracted, occupied elsewhere, or filtered through too thick a layer of pre-existing belief.

A second insight: **the stance is what distinguishes deliberate practice from random walking.** Two actors running the same loop with the same skill in each cycle will diverge over many cycles if one is feeding the loops correctly and the other is not. The compounding is not in the skill within a cycle; it is in the integrity of the loops between cycles.

A third insight: **the stance reorganizes what counts as winning.** A "win" within a cycle that depletes resources required for the next cycle is not a win in the iterated frame; a "loss" within a cycle that produces durable learning may be the cycle the iterated frame most needed. The stance is what reframes the unit of strategic assessment from the single cycle to the multi-cycle trajectory.

## Why Use This Thinking Tool

Three failure modes the framework prevents:

1. **One-cycle framing.** Treating the current cycle as if it were the only cycle erases the recursive prescription; high-PP / catastrophic-AA bets become reasonable selections when the cost of not being able to run the next cycle is not counted.
2. **Resource-loop denial.** Refusing to acknowledge that a cycle has depleted political capital, credibility, or attention bandwidth means the next cycle's capability gate is run against the wrong portfolio; the gate returns Yes when it should return No.
3. **Learning-loop corruption.** An observation node starved by distraction or pre-existing belief means the cycle's lessons are not actually being passed to the next cycle. The form of running cycles continues; the substance of cycle-to-cycle improvement does not.

For executives, founders, and any actor running multi-month or multi-year political work, the stance is what makes the framework actually compound rather than merely describe.

## How To Enter And Sustain The Stance

Iterated Loop Compounding is a stance, not a sequenced workflow. The discipline is what the actor pays attention to across cycle boundaries, not a checklist within a cycle.

1. **Maintain a written cycle record.** A simple log — one paragraph per cycle, dated, with the cycle's interest, action, intended outcome, actual outcome, perceived outcome, and the resource-loop and learning-loop deltas the cycle produced. The act of writing it is the stance's primary practice.
2. **At the start of each new cycle, re-read the prior cycle's record.** Specifically: what did the prior cycle leave for this one? What resources are depleted? What learning was recorded that this cycle's interest should reflect?
3. **Audit the loops explicitly at each cycle boundary.** Did the resource loop update honestly? (Or did the actor refuse to acknowledge a depletion?) Did the learning loop pass cleanly? (Or was the observation node starved during the cycle, leaving the lesson under-noticed?)
4. **Watch the multi-cycle trajectory, not the current cycle's outcome.** Ask, after every several cycles: is the agenda being served by the trajectory? Is the resource portfolio compounding or eroding? Is the actor's strategic position improving across cycles, or improving only within isolated cycles while eroding overall?
5. **Notice when the loops are running but not compounding.** This is the silent failure: form preserved, substance lost. The signal is that the actor is busy and the work feels strategic, but the resource portfolio is not actually getting deeper and the learning is not actually getting sharper.
6. **Treat the present cycle as accountable to a future cycle.** "How will I describe this cycle's outcome when I am running cycle N+3?" is the discipline's organizing question. It is the only question that catches one-cycle thinking before it lands as a bet.

A useful test: if the actor cannot articulate, in one sentence, how the previous cycle's outcome shaped the current cycle's starting condition, the loops have not actually been audited and the stance has not been entered.

## Worked Example

A founder eighteen months into running her startup as CTO of an early-stage company conducts an iterated-loop review of her decision to accept the CTO role.

- **Cycle 1 (the offer evaluation, 18 months ago):** interest = evaluate whether the role serves the agenda of becoming a technology executive whose judgment is structurally consequential. Decision: accept the revised offer. Expected utility = +5; actual utility = +5 (slightly higher because of an unprompted change-of-control acceleration concession); perceived utility = +5.
- **Cycle 2 (mid-role recalibration, 9 months in):** interest = test whether the cycle's actual trajectory is matching the cycle's expected trajectory. Company has grown 38 → 80 people; one significant architectural decision turned out wrong but was corrected within a quarter; eleven other significant decisions are holding. Resource portfolio: Credibility deepening (significant), Attributes sharpened by the operational scale, Access expanding (board interactions), Tribe growing (three director-level hires now reporting in). Learning loop: clean — the corrected architectural decision was caught and processed.
- **Cycle 3 (the eighteen-month checkpoint):** the loops have been running clean. Resource compounding is positive; learning compounding is positive; perception gap has narrowed across the three cycles (Field Manual p. 36). The recursive prescription is operating: each cycle's outcome is producing resources the next cycle can spend.

The stance's diagnostic value: the original decision to accept the CTO role was not validated by the single-cycle outcome (which could have been luck); it was validated by the multi-cycle trajectory. The stance reframes the eighteen-month review from "was the offer the right call?" to "is the iterated loop compounding the agenda?" The answer is yes — and the next cycle's interest now updates from "establish the role" to "extend the role's reach to the kind of decisions that compound further." (Adapted from Field Manual ch. 9, Talvyn / Jia Yarrow Eighteen months later, pp. 36-37.)

## Common Failure Modes

- **Cycle log abandoned mid-trajectory.** A multi-cycle log requires sustained discipline; abandoning it after the first few entries means the stance has lapsed into form-without-substance. Re-instate the log before declaring the stance lost.
- **Single-cycle wins celebrated as if the trajectory had compounded.** A within-cycle win that depleted resources required for the next cycle is not a compounding outcome. The trajectory-level read is what catches the misclassification.
- **Resource-loop denial.** "I am fine" without an honest portfolio audit at the cycle boundary is the canonical denial. The loop is corrupted; the next cycle's gate will return Yes on a portfolio that does not actually support the action.
- **Learning-loop assumed rather than audited.** "I learned from that" without specifying what was learned, where it was recorded, and how it has shaped the current cycle's interest is assertion, not auditing. The learning loop's corruption is invisible without the explicit pass.
- **Trajectory framed by cycle count, not cycle quality.** "I have been doing this for ten years" is not the same as "I have run ten cycles in which the loops compounded." The stance is about loop integrity, not duration.
- **Compounding mistaken for accumulation.** A bigger resource portfolio is not the same as a compounding one. Compounding means each cycle's outcome feeds the next cycle's capability — not just that the actor has more stuff than they did before.
