# Contractualism

**One-line summary:** A moral framework holding that an action is right if it can be justified to everyone affected by principles that no one could reasonably reject — emphasizing reason-giving across persons rather than rule-following or outcome-aggregation.

**When to reach for it:** Policy design where multiple stakeholder groups will be affected, regulatory analysis, organizational decisions affecting many parties, situations where "what could I justify to those affected?" is the relevant question, and as one of the four primary lenses in any serious ethical analysis.

---

## Purpose Of This Thinking Tool

T.M. Scanlon's *What We Owe to Each Other* (1998) developed contemporary contractualism as an alternative to both deontology (rule-based) and consequentialism (outcome-based). The core principle: **an action is wrong if it would be disallowed by any principle for the regulation of behavior that no one could reasonably reject.**

The non-obvious operational insight is that **contractualism centers reason-giving across persons.** Rather than asking "what does the rule require?" (deontology) or "what produces best aggregate outcomes?" (consequentialism), it asks "could I justify this to each affected party using reasons they could not reasonably reject?" The framework treats moral justification as fundamentally interpersonal — owed to specific others, not derivable from impersonal calculation.

The "could not reasonably reject" test does substantial work. It's not "would not reject" (people reject things for unreasonable reasons all the time) and not "would not refuse to consent" (a fully informed agent might refuse a fair deal for strategic reasons). The test is: given what a reasonable person could legitimately object to, would the principle survive that objection?

Scanlon's contractualism is closely related to (but distinct from) **John Rawls's contractualism**, which is the basis of the Veil of Ignorance (separate entry). Rawls's question is "what principles would rational agents choose for the basic structure of society if they didn't know their own position in it?" Scanlon's question is "what principles couldn't be reasonably rejected?" The two frameworks converge on many conclusions but emerge from different starting points.

A second insight: **contractualism is robust against the utilitarian-objection problem.** Pure utilitarian calculation can justify sacrificing one person for many; the deontological response is "sacrificing them violates a rule." The contractualist response is "the sacrificed person could reasonably reject this principle" — providing a positive reason rather than just a rule citation.

A third insight: **contractualism supports many institutional ethics conclusions.** Workplace fairness, due process, transparency, informed consent — all of these can be defended on contractualist grounds: they're principles whose absence the affected party could reasonably reject.

## Why Use This Thinking Tool

Three failure modes the framework prevents:

1. **The aggregation-without-justification trap.** Pure consequentialism can justify policies that benefit the majority at the expense of an identifiable minority. Contractualism asks "could I justify this to the minority?" — usually exposing the wrong.
2. **The rule-without-reason failure.** Pure rule-based ethics can produce justifications that feel arbitrary ("because the rule says so"). Contractualism requires the reasons for the rule to be ones no one could reasonably reject — making the reasons inspectable.
3. **The "I can do this because I want to" individualism.** Some forms of moral reasoning treat the agent's preferences as paramount. Contractualism centers what's owed to others; you cannot justify an action by appeal only to your own preferences.

For policy designers, regulators, organizational leaders, and anyone designing principles that will affect many parties, contractualism provides the question that other frameworks miss: "what reasons can I give to each affected party that they couldn't reasonably reject?"

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|    1 | Identify the action / principle / policy. State it as a candidate principle:     |
|      | "It is permissible to [X] when [conditions]."                                    |
|    2 | Identify everyone affected. Direct, indirect, future. Be inclusive.              |
|    3 | For each affected party, articulate their potential objection. What reasons       |
|      | might they have to reject this principle?                                        |
|    4 | Evaluate the reasonableness of each objection. Are they grounded in legitimate   |
|      | interests, or in unreasonable demands?                                           |
|    5 | If any party has a reasonable basis for rejecting the principle, the principle  |
|      | fails the contractualist test. Modify or reject.                                 |
|    6 | If the principle survives all reasonable objections, it's contractualistically  |
|      | permissible.                                                                     |
|    7 | Cross-check: would the principle's defenders accept it if they were in any of   |
|      | the affected positions? (Rawlsian variant.)                                      |
|    8 | Cross-check with other frameworks. Where they converge, confidence is high;     |
|      | where they diverge, the divergence is informative.                               |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
THE CONTRACTUALIST AUDIT TEMPLATE

   Proposed principle: ________________________________________

   AFFECTED PARTIES (be inclusive):
       Party A: _________________________________________
       Party B: _________________________________________
       Party C: _________________________________________
       (etc.)

   FOR EACH PARTY:
       What is their stake in this principle?
            _____________________________________________
       What reasonable objection could they raise?
            _____________________________________________
       Is the objection reasonable (grounded in legitimate
       interests)?
            Y / N
       If Y: how does the principle's defender respond?
            _____________________________________________

   VERDICT:
       If any party has a reasonable basis for rejection that
       survives the defender's response: principle FAILS.
       If all reasonable objections are addressable: principle
       SURVIVES the contractualist test.

THE "REASONABLE REJECTION" CRITERION

   What counts as reasonable rejection? Scanlon's criterion is
   that the person has substantial reasons grounded in their
   well-being, autonomy, or moral standing.

   COUNTS as reasonable rejection:
       - Bears disproportionate burden for marginal aggregate gain
       - Has rights / interests violated for inadequate reason
       - Treated as means rather than as person
       - Excluded from consideration / process
       - Subject to outcomes they couldn't have anticipated

   DOESN'T count as reasonable rejection:
       - Merely doesn't want the outcome
       - Has unreasonable demands (entitlement to everything)
       - Objects from a position of bad-faith bargaining
       - Wants advantage at others' clear expense

   The criterion does substantial work — getting it right is
   the framework's main interpretive task.

THE COMPLAINTS-COMPARISON METHOD

   When multiple parties have potential objections, compare:

   Whose complaint is strongest?
   Whose complaint, if upheld, has the smallest impact on others?
   Whose complaint reflects deepest interests vs. surface
   preferences?

   The strongest reasonable complaint that survives the others'
   responses is the operational test. If a principle satisfies
   even the strongest reasonable complaint, it survives.

THE INSTITUTIONAL APPLICATION

   For organizational / institutional design:

   Compensation policy:
       Could each employee class reasonably reject it given
       what they contribute / require / can credibly do
       elsewhere?

   Disciplinary policy:
       Could each role / context reasonably reject it given
       fair-process, proportionality, predictability concerns?

   Customer / data policy:
       Could each customer reasonably reject it given disclosure
       at decision-time, consent, and proportionate consideration?

   The contractualist test catches policies that "look fair" in
   the abstract but produce reasonable objections when applied to
   specific parties.

THE CONTRACTUALIST RESPONSE TO CLASSIC CASES

   Trolley problem: contractualism objects to the "fat man" variant
   (push him onto tracks to stop trolley) because he could
   reasonably reject the principle that he can be used as a means.
   The five could not reasonably reject the principle requiring
   doing something to save them, but the fat man can reasonably
   reject being the means.

   Organ harvesting: similar reasoning — the unwilling donor could
   reasonably reject the principle that allows their organs to be
   taken without consent, even for greater aggregate gain.

   Contractualism produces deontology-like conclusions in these
   cases without relying on rules — providing reasons that make
   the rules' content sensible.

THE COMPARISON TO THE FOUR FRAMEWORKS

   Deontology: rules from a single rational standpoint.
   Consequentialism: best outcome aggregated across persons.
   Virtue ethics: character of the agent.
   Contractualism: principles justifiable to each affected
                    person.

   Same case, four lenses, sometimes converging, sometimes not.
   Where they converge, ethical confidence is high. Where they
   diverge, the divergence reveals the structural choice that
   each framework illuminates differently.

THE REASONABLE-DISAGREEMENT QUESTION

   Two contractualists may disagree about which objections are
   reasonable. This is a feature, not a bug — the framework
   provides a structured discussion, not an algorithm.

   Common interpretive questions:
       Whose perspective do we take in evaluating reasonableness?
       How weighty must an interest be to ground reasonable
       rejection?
       What counts as "burdens" vs. "preferences"?
       How do we handle parties with adaptive preferences (those
       who've adjusted to bad situations and don't object)?

   These questions don't dissolve the framework; they're the
   substantive territory in which contractualist analysis
   proceeds.

THE QUICK-USE TEMPLATE

   Principle: __________________________________________________

   Affected parties: ___________________________________________

   For each party, what's their reasonable objection?
       Party A: __________________________________________________
       Party B: __________________________________________________
       Party C: __________________________________________________

   Are these objections survivable by the principle's defense?
       _____________________________________________________

   Verdict (contractualist): permissible / impermissible /
   contested

   Cross-check with other frameworks.
```

> **Operational notes:** Four disciplines. (1) Center reason-giving across persons, not aggregate calculation or rule-citation. The contractualist test is "what reasons can I give that no one could reasonably reject?" This produces different conclusions from utilitarianism in cases involving sacrifice of identifiable individuals. (2) The "reasonably reject" criterion does substantial work. Getting it right requires careful attention to whose interests count, what burdens are disproportionate, and what counts as fair process. The framework's interpretive challenge is here. (3) Contractualism is institutionally powerful. Many organizational and policy ethics conclusions (fair process, informed consent, transparency, proportional treatment) are well-defended on contractualist grounds. Use it for institutional ethics design. (4) Use as one of four lenses. Where contractualism, deontology, consequentialism, and virtue ethics converge, confidence is high. Where they diverge, the divergence reveals the structural shape of the dilemma; no single framework is sufficient.
