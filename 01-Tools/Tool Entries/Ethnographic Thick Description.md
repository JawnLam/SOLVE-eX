# Ethnographic Thick Description

**One-line summary:** A descriptive method that captures not just what people do but the *meaning* their actions carry within their cultural context — layering interpretation onto observation to make sense visible to outsiders.

**When to reach for it:** Customer-discovery research, organizational diagnosis, market entry into unfamiliar contexts, change-management sense-making, and any situation where surface behavior tells only a fraction of the story.

---

## Purpose Of This Thinking Tool

Geertz's example: a person rapidly closes one eye. *Thin* description: "eyelid contracted." *Thick* description: "a wink, signalling ironic complicity." Thicker still: "a parody-of-a-wink, mocking conspiratorial behavior." Same physical event, radically different meanings — and only the thick version is operationally useful.

The non-obvious operational insight: thick description is *layered interpretation*, not just detail. Adding more sensory detail ("the wink lasted 0.3 seconds, the corner of the mouth raised 4mm") is still thin. What thickens description is *naming the cultural code* the actor is using — what game they're playing, what convention they're invoking, what category their action fits in their world.

Geertz introduced the concept in *The Interpretation of Cultures* (1973), grounding it in Gilbert Ryle's earlier philosophical use. It became foundational for interpretive ethnography, qualitative organization studies, and design ethnography. In product and service research, "thick description" of user behavior in context is what distinguishes useful research from observation logs.

## Why Use This Thinking Tool

Three failure modes thick description prevents:

1. **Surface-only behavior data.** Logged actions ("user clicked X then Y") explain nothing about *why* — the meaning the user was making. Thick description supplies that.
2. **Imposition of researcher categories.** Thin description in researcher's vocabulary smuggles in foreign concepts. Thick description anchors in participants' own categories.
3. **Misread customer intent.** "Customer said they want X" is thin; "Customer used 'X' as a placeholder for the broader concern about Y, which is what their organization currently lacks vocabulary for" is thick — and far more actionable.

For consulting and customer-discovery work, thick description is the discipline that converts raw fieldwork into usable insight. The artifact is a written description that carries the meaning, not just the events.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|    1 | Observe / interview in setting. Take *thin* notes (verbatim quotes, observed     |
|      | actions, time, place) — fast and faithful.                                      |
|    2 | Within 24h while memory is fresh, expand thin notes into thick description:    |
|      | what was happening, what cultural codes were being used, what would an           |
|      | informed insider have noticed?                                                  |
|    3 | Distinguish three layers: behavior, participants' interpretation, your          |
|      | interpretation of their interpretation.                                         |
|    4 | Test interpretations: would the participants recognize themselves in this        |
|      | description? Would they accept the meanings you've named?                       |
|    5 | Triangulate: do other observations fit the interpretive frame? Find at least    |
|      | one disconfirming case before committing.                                       |
|    6 | Write up: combine thin observation with thick interpretation, marking which is  |
|      | which. The output is a *legible* account a non-participant can use.             |
|    7 | Member-check if possible: show the description to a participant; if they say    |
|      | "yes, but" — listen.                                                            |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
THICK DESCRIPTION TEMPLATE

    Setting (place, time, conditions): __________________________________________
    Participants (roles, relationships): ________________________________________
    Researcher's role / position: _______________________________________________

    LAYER 1 — THIN OBSERVATION (fast, faithful, factual)
      What I saw / heard:
        ______________________________________________________________________
        ______________________________________________________________________
      Verbatim quotes:
        Person A: "_______________________________________________________"
        Person B: "_______________________________________________________"

    LAYER 2 — PARTICIPANTS' INTERPRETATION
      What were they doing — in their own terms?
        ______________________________________________________________________
      What cultural code / convention / game were they playing?
        ______________________________________________________________________
      What did this action *mean* to them?
        ______________________________________________________________________

    LAYER 3 — RESEARCHER'S INTERPRETATION OF THEIR INTERPRETATION
      Why this code, in this context?
        ______________________________________________________________________
      What is the action *doing* socially / strategically / institutionally?
        ______________________________________________________________________
      What does this tell us about the system the participants live in?
        ______________________________________________________________________

    PREJUDGMENT CHECK
      What did I expect to see? __________________________________________
      What surprised me? _________________________________________________
      Where did my interpretive frame strain to accommodate the data? ____

    TRIANGULATION
      Other observations consistent with Layer 3 reading: ____________________
      Disconfirming or tension-introducing observations: _____________________

    MEMBER-CHECK
      Did a participant recognize themselves in the description?  □ yes  □ partial
      What did they correct / push back on? _________________________________

GEERTZ'S WINK LADDER (calibrate your thickness)

      Layer            | Description
      -----------------|------------------------------------------------------
      Behavior         | "eyelid contracts rapidly"
      Public meaning   | "a wink"
      Conventional use | "a wink as conspiratorial signal"
      Performed use    | "a wink mocking the conspiratorial-signal convention"
      Stratified use   | "a wink mocking, by an outsider performing local register"
      → Each step adds interpretive load, not factual detail.
```

> **Operational notes:** Three disciplines compound the value. (1) Thicken slowly — going straight from thin to layer-3 invites projection. The Layer-2 step (participants' own terms) is the discipline that prevents researcher categories from overwriting native ones. (2) Always seek a disconfirming observation. Thick description is interpretive, and interpretation is prone to confirmation. A finding that *no* observation contradicts is suspicious; usually that means you've stopped looking. (3) Member-check when possible. Letting a participant read and respond to the description is the strongest available test of whether the interpretation is recognizable to the people whose actions are described. Their corrections are gold. Fourth: distinguish layers in the written output. Readers — including future-you — need to know which sentences are observation and which are interpretation; combining them invisibly turns interpretation into "data."
