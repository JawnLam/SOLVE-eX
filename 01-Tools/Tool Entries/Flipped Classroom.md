# Flipped Classroom

**One-line summary:** Content delivery (lecture-equivalent) happens at home via video; classroom time is spent on application, problem-solving, and discussion.

**When to reach for it:** Courses where in-class time is dominated by content delivery but students need more application practice; subjects where pre-recorded video is acceptable for content; teachers seeking to increase active-learning time.

## Purpose

Standard education spends class time on content delivery (lectures) and homework time on application (problem sets). Flipped Classroom inverts this. Pre-recorded videos deliver content; class time is freed for problem-solving with peer and teacher support. The method addresses the common failure mode where students struggle alone on homework after passive in-class lectures. Evidence for effectiveness is mixed and depends on implementation quality; the model works best when video content is high-quality and class time is genuinely active.

## How To Use

1) Prepare video content for each unit (10-15 min). 2) Assign as pre-class homework. 3) Use class time for problem-solving, discussion, application, formative assessment. 4) Provide accountability for video viewing (pre-class quizzes). 5) Use class time for the activities that genuinely benefit from synchronous peer/teacher interaction.
