# Nyaya Five-Step Syllogism

**One-line summary:** Classical Indian logic (Gautama, ~2nd c. BCE-2nd c. CE): proof requires five elements — pratijñā (thesis), hetu (reason), udāharaṇa (example), upanaya (application), nigamana (conclusion). Distinct from Aristotelian syllogism by requiring an empirical exemplifying instance.

**When to reach for it:** Cross-cultural philosophical analysis, history of logic, or any rigorous argument where the analyst wants to explicitly check whether the proof grounds itself in observable example. Useful contrast with Western syllogistic forms.

## Purpose

Aristotelian syllogism is purely formal — "all M are P, S is M, therefore S is P" — without requiring that the major premise be exemplified. Nyaya logic insists on the example: the reason connecting the term to the predicate must be illustrated by a known instance (positive example) AND a known contrary instance (negative example). This grounds inference in empirical observation; the syllogism does not float free of the world.

## How To Use

Standard example: "The mountain has fire because there is smoke; wherever there is smoke, there is fire (as in a kitchen); the mountain has smoke; therefore the mountain has fire."

1. **Pratijñā (thesis)** — State the claim. *("The mountain has fire.")*
2. **Hetu (reason)** — Give the reason. *("Because there is smoke.")*
3. **Udāharaṇa (example)** — Cite a positive instance ("as in a kitchen, where smoke implies fire") and a negative instance ("unlike in a lake, where there's no smoke and no fire").
4. **Upanaya (application)** — Apply the rule to the specific case ("and there *is* smoke on the mountain, like in the kitchen").
5. **Nigamana (conclusion)** — State the conclusion ("therefore the mountain has fire").
