# AIDA (Attention-Interest-Desire-Action)

**One-line summary:** A four-stage persuasion sequence — gain Attention, build Interest, create Desire, prompt Action — used in copywriting, sales, and campaign design.

**When to reach for it:** Writing persuasive copy, designing sales conversations, structuring marketing campaigns; checking whether a message contains all four stages.

## Purpose

AIDA breaks persuasion into stages with distinct functions: each stage has its own move and skipping any one tends to break the funnel. Attention without Interest is forgotten; Interest without Desire is academic; Desire without Action prompt is unconsummated. The tool is the explicit four-stage checklist for any persuasion artifact.

## How To Use

1) Attention: open with a hook that interrupts the reader's current state. 2) Interest: provide information that makes the topic personally relevant. 3) Desire: shift from informational to motivational — show what could be possessed/achieved. 4) Action: provide a specific, low-friction next step. 5) Audit: each stage present?
