# A3 Thinking

**One-line summary:** Single-page (A3 size) structured problem-solving artifact — background, current condition, root cause, target, countermeasures, plan, follow-up — used at Toyota to develop manager PDCA thinking.

**When to reach for it:** When tackling a non-trivial operational or process problem that requires collaborative diagnosis and a documented improvement plan. A3 is both deliverable and developmental artifact — the author's thinking is visible on the page.

## Purpose

A3 forces compression. The constraint of fitting a problem analysis onto a single A3-sized sheet (~11×17 inches) requires the author to clarify what's essential and prune what isn't. At Toyota, the A3 is not a report — it's a *thinking tool*: the manager iterates on the A3 with peers and a sensei, with successive drafts surfacing where the reasoning is weak. The improved A3 is improved thinking.

## How To Use

Left column (current state):
1. **Background** — Context, why this problem matters.
2. **Current Condition** — Quantified description of how things are now.
3. **Goal / Target Condition** — Where we want to be (with metrics).
4. **Root Cause Analysis** — Why is the gap there? (5 Whys, fishbone, etc.)

Right column (future state):
5. **Countermeasures** — Specific interventions.
6. **Implementation Plan** — Who, what, when.
7. **Follow-up** — How will we know it worked? When will we check?

Iterate the A3 with peers and supervisor; pause to improve thinking, not just polish prose.
