# Reference Class Forecasting

**One-line summary:** Forecast by finding the population of similar past cases and using their outcome distribution — bypasses the planning fallacy's insider-view optimism.

**When to reach for it:** Project-duration estimation, cost forecasting, success-probability assessment for ventures with similar predecessors; any context where insider intuition systematically over-predicts.

## Purpose

Inside-view forecasts (built bottom-up from the specific case's features) systematically underestimate cost, time, and failure rates because they neglect the base rate of similar projects. Outside-view forecasts use the reference class to anchor predictions in observed outcomes. Flyvbjerg showed reference-class methods produce dramatically more accurate megaproject forecasts than insider methods. The discipline is identifying the reference class first, anchoring on its distribution, then adjusting for case-specific factors only marginally.

## How To Use

1) Identify the reference class — projects with the same structure, size, and context. 2) Gather their outcome distribution (means, medians, percentile spreads). 3) Anchor the forecast on the distribution's central tendency. 4) Adjust modestly for case-specific factors — typically less than insider intuition suggests. 5) Communicate the forecast with reference-class context so readers know the basis.
