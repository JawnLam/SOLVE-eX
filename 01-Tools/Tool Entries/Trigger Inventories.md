# Trigger Inventories

**One-line summary:** A structured personal catalog of situations, cues, and body states that reliably activate specific reactive patterns — paired with early-warning signs and pre-planned responses, kept current via reflective practice.

**When to reach for it:** Self-management work where reactive patterns are recurring; addiction or behavioral-change recovery; conflict-heavy roles where leader regulation matters; couples / partnership work where mutual triggers shape interaction; or as a general practice for self-knowledge.

---

## Purpose Of This Thinking Tool

Reactive patterns are highly individual, but they're also predictable per person. The same person reliably escalates around the same situations: a particular tone of voice, a specific kind of feedback, a body state (low blood sugar, sleep deprivation), an institutional cue (a calendar item from a particular sender). A *trigger inventory* makes these explicit — turning chronic surprise ("why did I lose it again?") into anticipatable, manageable territory.

The non-obvious operational insight is that triggers usually have *early-warning signs* in the body before the reaction crystallizes. A small tightening in the chest, a specific tone of self-talk, a flush of heat, a sudden urge to check the phone. By inventorying not just the trigger but the early-warning sign, you create a window of agency — the moment when the pattern can still be caught and redirected.

The practice descends from cognitive-behavioral and dialectical-behavioral therapy, addiction-recovery frameworks (relapse-prevention planning), and clinical formulation work. It generalizes broadly to non-clinical self-management.

## Why Use This Thinking Tool

Three failure modes the explicit inventory prevents:

1. **Surprise-as-norm.** Without the inventory, recurring patterns look like fresh failures each time; the inventory turns them into recognizable territory.
2. **Late-stage intervention.** By the time a reactive pattern is fully active, intervention is hard. Early warning shifts the intervention upstream.
3. **Generic coping.** "Just take a breath" doesn't match the specific pattern. Pre-planned responses tied to specific triggers are operationally tighter.

For consulting and leadership work, trigger inventories are an underused self-management tool. Most leaders have predictable activation patterns; explicit awareness shifts the floor on how-bad-it-can-get without requiring deeper therapeutic work.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|    1 | Look back over recent reactive moments (anger, panic, withdrawal, urge, etc.). |
|    2 | For each, identify the trigger: situation, cue, body state, person, time of    |
|      | day, social context.                                                            |
|    3 | Identify the early-warning sign — what was in your body / mind 30 seconds       |
|      | before the reaction crystallized?                                               |
|    4 | Build the inventory: trigger → early warning → typical reactive pattern →       |
|      | pre-planned response.                                                           |
|    5 | Practice noticing early warnings during the day. The skill is recognition       |
|      | itself; intervention follows.                                                   |
|    6 | When a trigger fires and you notice the early warning, apply the pre-planned   |
|      | response. Track outcome.                                                        |
|    7 | Update inventory periodically. New triggers arise; old ones may attenuate.      |
|    8 | If patterns are severe or trauma-related, work with a clinician — the           |
|      | inventory is a complement, not substitute, for treatment.                       |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
TRIGGER INVENTORY TEMPLATE

      Trigger / Cue        | Early-warning sign      | Reactive pattern           | Pre-planned response
      ---------------------|-------------------------|----------------------------|---------------------------
      e.g., critical email | tightness in chest;     | defensive reply,           | step away 10 min; call
      from Person X        | self-talk "they think   | escalates the conflict    | trusted peer; draft reply
                           | I'm stupid"             |                            | offline; review at +1h
      ---------------------|-------------------------|----------------------------|---------------------------
                           |                         |                            |
                           |                         |                            |
                           |                         |                            |

CATEGORIES OF TRIGGERS (helps inventory completeness)

    [ ] INTERPERSONAL — specific people, tones, criticism, conflict, demands
    [ ] INSTITUTIONAL — particular meetings, deadlines, evaluation contexts
    [ ] BODY STATES — hunger, low sleep, illness, hormonal shifts, alcohol
    [ ] EMOTIONAL — feeling unseen, ignored, rushed, controlled, infantilized
    [ ] ENVIRONMENTAL — crowded spaces, specific locations, sensory overload
    [ ] TIME-OF-DAY — late-night fragility, post-meeting depletion
    [ ] HISTORICAL ECHOES — situations that resemble older difficult ones
    [ ] SUBSTANCE / DIGITAL — alcohol, social media doom-scroll, news cycle

EARLY-WARNING SIGN MAP

    Bodily:    where in my body do warnings show up?
      [ ] chest tightening    [ ] jaw clench       [ ] stomach drop
      [ ] hands cold / hot    [ ] shoulders rise   [ ] breath shorten
      [ ] tunnel vision       [ ] tinnitus / ear ringing
      [ ] urge to flee / freeze / lash

    Cognitive:
      [ ] specific self-talk phrases ("they're attacking me", "I'm stupid")
      [ ] sudden urge to check phone / drink / eat / scroll
      [ ] mind speeding up / blanking out
      [ ] catastrophizing / mind-reading thoughts

    Behavioral:
      [ ] urge to walk away
      [ ] urge to argue / win
      [ ] urge to comply / appease
      [ ] urge to numb / disappear

PRE-PLANNED RESPONSE MENU

    Per trigger, pick an intervention proportionate to severity:

    Mild trigger (early warning, before crystallization):
      • single deep breath, longer exhale
      • name what's happening internally ("Anxiety is here")
      • micro-movement (hand to chest, feet press to floor)

    Moderate trigger (warning ignored, beginning to react):
      • pause / step out for 2–10 min
      • call / text trusted peer
      • draft response offline; review at +1h

    Severe trigger (already partly activated):
      • leave the situation if possible
      • contact accountability person
      • return to baseline before re-engaging
      • do NOT make decisions or send messages while activated

DAILY PRACTICE PROMPT

    Each evening, brief review:
      Triggers fired today:                _________________________
      Early warnings I caught in time:     _________________________
      Early warnings I missed:             _________________________
      Pre-planned responses applied:       _________________________
      Anything to add to the inventory?    _________________________

UPDATE CADENCE

    Initial: build inventory in 1–2 reflective sessions
    Weekly: review missed warnings; add new triggers
    Quarterly: audit whole inventory; some triggers attenuate as patterns soften
```

> **Operational notes:** Three disciplines. (1) Don't moralize the triggers. They're not failures; they're patterns. The inventory is a tool of self-knowledge, not self-judgment. Inventorying with shame produces avoidance; inventorying with curiosity produces information. (2) Catch early warnings, not crystallized reactions. The window of agency is the early warning. By the time the reaction is fully active, prevention is past; the work then is damage control. Building recognition of early warnings is the actual skill the inventory cultivates. (3) Pre-plan responses specifically. Generic "take a breath" advice underperforms specific responses tied to specific triggers. The inventory's power is in matching response to pattern. Fourth: pair with body-aware practices. Triggers usually have somatic dimensions (tightness, breath, body state); body-aware practices (Polyvagal-informed regulation, Focusing, Feldenkrais) make the early-warning recognition faster and more reliable. The inventory is the artifact; the skills are the practice.
