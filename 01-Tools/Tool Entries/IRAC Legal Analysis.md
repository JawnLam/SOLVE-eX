# IRAC / CREAC Legal Analysis

**One-line summary:** Issue-Rule-Application-Conclusion (or CREAC: Conclusion-Rule-Explanation-Application-Conclusion) framework for structuring legal analysis. Standard scaffold in US/Commonwealth legal writing.

**When to reach for it:** Writing any legal analysis — bar exam answers, memos, briefs, judicial opinions. Also useful for teaching analytical writing in non-legal domains where rule-application reasoning is central.

## Purpose

Legal analysis is structurally distinct from essay writing — the reader needs to know precisely what rule is being applied and how the facts trigger it. IRAC enforces this. The CREAC variant moves Conclusion to the front (persuasive writing) and adds explicit Rule Explanation (a separate step before application), preventing the common error of applying a rule the reader doesn't yet understand.

## How To Use

**IRAC:**
1. **Issue** — Frame the legal question.
2. **Rule** — State the controlling rule (statute, precedent, doctrine).
3. **Application** — Apply the rule to the facts, addressing counterarguments.
4. **Conclusion** — State what follows.

**CREAC** (for persuasive writing):
1. **Conclusion** — Lead with the answer.
2. **Rule** — State the rule.
3. **Explanation** — Unpack what the rule means; cite supporting authority.
4. **Application** — Apply to facts.
5. **Conclusion** — Restate.
