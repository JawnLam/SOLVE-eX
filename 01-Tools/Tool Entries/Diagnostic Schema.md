# Diagnostic Schema

**One-line summary:** An organized clinical-knowledge framework (anatomic, organ-system, physiologic, or based on pivotal-points) that bridges problem representation and differential diagnosis.

**When to reach for it:** When a clinician faces a problem that has too-many possible causes to enumerate without structure (chest pain, shortness of breath, abdominal pain). Used heavily in training to scaffold the move from "I know facts" to "I can think like a clinician."

## Purpose

Diagnostic schemas organize knowledge into clinically-useful subcategories rather than alphabetical lists or textbook chapters. Anatomic schemas group by location; system schemas by organ-system; physiologic schemas by mechanism. Trainees with schemas outperform those without on diagnostic accuracy — the schema is the cognitive bridge that takes "problem representation" (this patient's summary) and produces "differential diagnosis" (ranked list of candidates).

## How To Use

1. **Identify the problem.** Translate patient's presentation into a one-line problem representation.
2. **Select a schema** appropriate to the problem type (e.g., chest pain → cardiac/pulmonary/GI/MSK/psych anatomic schema).
3. **Traverse the schema** systematically — for each branch, evaluate plausibility against patient data.
4. **Rank the differential** by probability and severity.
