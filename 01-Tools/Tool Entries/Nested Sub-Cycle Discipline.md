# Nested Sub-Cycle Discipline

**One-line summary:** A cycle-stack discipline for managing the sub-cycles that open when the required-resource check returns No — each sub-cycle has its own target and decision matrix, may itself require further sub-cycles, and the discipline is maintaining the stack so the original interest is preserved across the nesting and the actor returns to the parent cycle when the sub-cycle closes.

**When to reach for it:** Whenever a required-resource check returns No and a sub-cycle is opened to procure the missing resource; when an actor's strategic work has been running for multiple weeks or months and the original interest has become difficult to articulate (a stack-loss diagnostic); when a procurement effort (hiring, fundraising, coalition-building) has begun to feel like the strategic work itself rather than the means to it; when reviewing past strategic work to determine why an originally-defined interest never closed. Especially valuable when a sub-cycle is itself producing sub-cycles three levels deep — the failure mode is at that depth, not at the surface.

---

## Purpose Of This Thinking Tool

**Nested Sub-Cycle Discipline** is the cycle-stack discipline the ADAPT Loop requires when the procurement of resources is itself political work. The dissertation observes the pattern across the 5 case-study formal traces (Lam 2020 saturation Tables 5-22): when an actor's required-resource check returns No, they open a sub-cycle to procure the missing resource; the sub-cycle has its own target, its own decision matrix, and frequently opens further sub-cycles. Three deep is observed (Sarah → Margaret, requiring Sarah → Beth as sub-cycle, requiring Sarah → other-party as sub-sub-cycle, dissertation Table 14 pp. 195-196). Nathan opens 4 sub-cycles within a single agenda cycle (dissertation Tables 7-12 pp. 175-188); Rusty opens 3 within the Rusty → Todd umbrella (dissertation Tables 17-21 pp. 207-216).

The non-obvious operational insight: **the sub-cycle is a full ADAPT cycle in its own right.** It has its own Actor → Agenda → Interest → Objective → Goal → Target ladder (the original Actor; the sub-cycle interest is "procure the missing resource"; the sub-cycle target is the party that controls that resource). It runs its own capability gate. It may itself fail and open further sub-cycles. Treating the sub-cycle as a tactical errand rather than a full cycle is the canonical mistake.

A second insight: **stack discipline.** The actor must maintain orientation toward the parent cycle's interest across the sub-cycle's execution. Without explicit stack tracking, the sub-cycle becomes the de facto current strategic effort and the original interest is forgotten. The dissertation cases that succeed are characterized by stack discipline; the cases that fail are typically characterized by stack-loss — the actor became absorbed in the procurement and stopped attending to the parent cycle's evolving conditions.

A third insight: **sub-cycle closure must be explicit.** A sub-cycle has closed when its target has been moved (the resource has been procured) or when it has been abandoned in favor of a different sub-cycle. Without explicit closure, the actor carries an open sub-cycle into the parent cycle's resumption and the strategic conversation is muddied — is the parent cycle's gate now passable, or is the sub-cycle still in progress?

## Why Use This Thinking Tool

Three failure modes the framework prevents:

1. **Stack loss.** The sub-cycle absorbs the actor's attention; the parent cycle's interest is forgotten; the work continues but no longer serves the agenda it was opened from.
2. **Sub-cycle treated as errand.** Failing to recognize the sub-cycle as a full ADAPT cycle means it is run without a decision matrix or a capability gate. The actor improvises within the sub-cycle and produces sub-optimal procurement.
3. **No explicit closure.** A sub-cycle that has functionally completed but has not been marked closed leaves the parent cycle's gate ambiguous. The actor either returns to the parent prematurely (resource not actually procured) or delays return indefinitely (sub-cycle work continues past necessity).

For executives, founders, and any actor running multi-month political work, the discipline is what preserves strategic coherence across deeply nested procurement.

## How To Use This Thinking Tool

The discipline is a stack-tracking practice combined with a sub-cycle protocol. Worked over a long horizon (weeks to months), the practical artifact is a written cycle stack the actor updates as cycles open and close.

1. **When the parent cycle's gate returns No, name the missing resource explicitly.** Use the 9-Resource taxonomy (see `9-Resource Portfolio Diagnostic`) to name precisely what is needed. Vague naming produces vague sub-cycles.
2. **Open the sub-cycle as a full ADAPT cycle.** Run Actor-Agenda Decomposition for the sub-cycle: who is the sub-cycle's target, what is the sub-cycle's interest (procure resource X), what is its objective and goal, what action moves the sub-target.
3. **Write the cycle stack.** A simple list: Parent (Cycle 1.0: original interest, suspended pending sub-cycle), Sub (Cycle 1.1: procure resource X), Sub-sub if needed (Cycle 1.1.1). The notation is less important than the explicit record.
4. **Run the sub-cycle to its own closure.** Capability gate, decision matrix, action, perception gap audit — the sub-cycle is a full cycle. If the sub-cycle's gate returns No, open a sub-sub-cycle (do not abandon).
5. **Mark sub-cycle closure explicitly.** Was the missing resource procured? Was it procured in full or partially? Did the sub-cycle's outcome reshape the parent cycle's resource portfolio in unexpected ways?
6. **Return to the parent cycle with updated state.** Re-run the parent cycle's capability gate with the now-procured resource. If the gate now returns Yes, the parent cycle proceeds. If still No, either the sub-cycle's procurement was insufficient (open another sub-cycle) or the parent cycle's required-resource specification was wrong (re-run the diagnostic).

A useful test: if the actor cannot, at any moment, articulate which cycle they are currently working on AND the parent cycle's interest, they have lost the stack and the discipline has not been maintained.

## Worked Example

A regional VP opens Cycle 1 with the interest "establish a credible claim that operations is the home of analytical decision-making in the firm." The action is a pilot proposal, approved with unfavorable governance. Cycle 1 closes with Actual utility +1, Perceived utility +3 (perception gap noted).

Cycle 2's gate returns No on the action she initially considered (a formal restructuring proposal). Rather than plowing ahead or abandoning, she opens a sub-cycle: procure the missing resource "the CFO's active sponsorship of operations-led analytics."

The sub-cycle is a full ADAPT cycle. Sub-cycle interest: convert CFO's neutral support into active sponsorship. Sub-cycle target: the CFO. Sub-cycle objective: secure the CFO's public attribution of the pilot's margin result to operations-driven analytical discipline. Sub-cycle action: a series of small briefings, a quarter of careful credit-attribution language in pilot reports, an explicit ask in a private meeting at the right moment.

Six months later, the sub-cycle has closed (CFO has begun publicly attributing the result to "an operating discipline that ran from the demand model through to the work order" — the VP's own language; this is the sub-cycle's success). She returns to the parent cycle. The parent's gate now returns Yes. Cycle 3 (the parent cycle's continuation) selects an option that was not viable at Cycle 1 — propose splitting the analytics group. The proposal is approved. (Adapted from Field Manual ch. 7, Cresterly Cycles 2-3, pp. 23-25; underlying dissertation pattern: Rusty's multi-target sub-cycle architecture, dissertation Tables 17-21.)

The discipline is what made Cycle 3 decisive. Without the stack discipline, the sub-cycle would have either consumed the VP's strategic attention entirely (stack loss) or been abandoned for not being "the real work."

## Common Failure Modes

- **Sub-cycle absorbs the strategic identity.** The actor begins to see the sub-cycle's target as the primary target; the original interest erodes; the work continues but no longer compounds toward the agenda.
- **Sub-cycle as errand.** Treating the sub-cycle as a quick procurement task rather than a full cycle means it runs without a capability gate, without a decision matrix, without perception-gap auditing. Sub-cycles deserve the discipline of the framework.
- **No explicit stack.** Without writing the cycle stack down, the actor loses track at depth. Three-deep nesting (observed in dissertation cases) is impossible to sustain without an explicit record.
- **Premature return to parent.** Returning to the parent cycle before the sub-cycle has actually closed means re-running the parent's gate with an unprocured resource — the gate returns No again, the actor reopens the same sub-cycle, time is lost.
- **Indefinite sub-cycle.** A sub-cycle that has functionally completed but has not been marked closed continues to absorb attention. Explicit closure is the discipline that ends it.
- **Stack-pop at the wrong level.** Returning to a grandparent cycle when the parent is still open is a stack-discipline error. Pop one level at a time.
