# Cross-Impact Analysis (Gordon-Hayward)

**One-line summary:** An n x n matrix capturing how each event affects each other event's probability — allowing analysis of compound futures rather than independent ones.

**When to reach for it:** Foresight analysis where events plausibly affect each other; technology assessment, geopolitical analysis, scenario probability adjustment.

## Purpose

Standard probability assessment treats events as independent and misses the structure of interdependence. Cross-Impact Analysis makes the dependencies explicit: for each pair of events (E_i, E_j), the analyst estimates how E_i occurring would shift the probability of E_j. The resulting matrix captures rich conditional structure. Monte Carlo over the matrix produces compound scenario probabilities that account for the dependencies.

## How To Use

1) Enumerate events of interest. 2) Estimate independent probability of each. 3) For each ordered pair, estimate conditional impact (e.g., +20%, -30%). 4) Build the cross-impact matrix. 5) Run Monte Carlo simulation to derive joint scenario probabilities. 6) Identify scenarios with high probability after dependencies are accounted for.
