# ARIZ (Algorithm for Inventive Problem Solving)

**One-line summary:** A multi-stage algorithm that orchestrates classical TRIZ tools (Principles, Su-Field, IFR, Separation, Resources, STC, 9-Windows) into a structured workflow.

**When to reach for it:** Complex engineering problems where multiple TRIZ tools are needed in sequence; expert-led innovation workshops; formal innovation methodology in R&D organizations.

## Purpose

ARIZ is the TRIZ master algorithm: classical TRIZ tools work well individually but in real problems must be combined. ARIZ specifies the order: problem analysis, contradiction formulation, IFR formulation, resource analysis, application of Principles via the Matrix, evaluation. Each iteration of ARIZ (ARIZ-71, -77, -85C, etc.) refined the steps. ARIZ-85C remains the most-cited version in pedagogy.

## How To Use

1) Analyze the initial problem and identify the technical conflict. 2) Reformulate to a model conflict (the abstracted contradiction). 3) Apply IFR to define the ideal outcome. 4) Mobilize resources. 5) Apply Inventive Principles via the Contradiction Matrix. 6) Develop solutions. 7) Apply to similar problems for generalization.
