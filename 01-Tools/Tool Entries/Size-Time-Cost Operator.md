# Size-Time-Cost Operator (STC)

**One-line summary:** A thought-experiment protocol — imagine size, time, or cost going to 0 or to infinity — to surface contradictions and identify resources.

**When to reach for it:** When the conventional system feels inevitable; when stuck on a contradiction; rapid creativity exercises during ARIZ.

## Purpose

STC is a structured creativity stimulus: take a key parameter and push it to extremes, asking what happens. If size went to zero, does the contradiction persist? If time were infinite, what would the right design be? If cost were zero, what would change? The extreme thought-experiments often surface hidden assumptions and resources that the conventional 'realistic' framing keeps invisible. The protocol forces the question 'why is the current value of this parameter assumed fixed?'

## How To Use

1) Identify the contradiction or design challenge. 2) Pick a parameter (size, time, cost). 3) Imagine it = 0; what does the system look like? What goes wrong? 4) Imagine it = infinity; same questions. 5) The answers reveal hidden assumptions, resource opportunities, or paths to dissolving the contradiction. 6) Generalize back to the original problem.
