# SCQA

**One-line summary:** A four-part introduction template — Situation, Complication, Question, Answer — that opens any business document or argument by establishing common ground, naming what changed, surfacing the question that change creates, and stating the answer up front.

**When to reach for it:** Executive memos, consulting deliverables, board briefings, strategic recommendations, any communication where the audience is busy, sophisticated, and needs the answer before the explanation. The default opening template for analytical writing.

---

## Purpose Of This Thinking Tool

SCQA is the introductory framework Barbara Minto formalized for McKinsey in the 1960s and published in *The Pyramid Principle* (1973). The four moves:

- **Situation** — what the audience already knows / accepts about the world. Common ground.
- **Complication** — what changed; the tension that disturbs the situation and creates a problem.
- **Question** — the question the complication forces the audience to ask.
- **Answer** — the document's main message, stated directly.

The non-obvious operational insight is that **the audience must agree with the Situation before the rest works.** A Situation the audience disputes turns the entire argument into a debate about the premise. The Situation should therefore be the most blandly accepted statement available — what no reasonable audience member would contest. The Complication can then introduce the disturbance without resistance, and the Question and Answer follow naturally.

The second insight is that **SCQA is upside-down compared to most natural writing.** Inexperienced writers state the Answer last, after building the case. Minto's claim is that executive audiences want the Answer first, with the case below in supporting structure (the rest of the Pyramid Principle). SCQA delivers the Answer in the introduction, then the body of the document supports it.

Three patterns of SCQA use, in increasing complexity:

- **Standard (S→C→Q→A):** Use when the audience needs the lead-up. Default form.
- **Direct (Q→A→S→C support):** Use when the audience knows the situation and wants the answer first.
- **Concern-leading (C→S→Q→A):** Use when the complication is the point of the document — typically crisis or urgency communications.

## Why Use This Thinking Tool

Three failure modes SCQA prevents:

1. **The "context dump" opening.** Writers who lead with extensive background (history, methodology, assumptions) lose the audience before stating the question. SCQA limits the opening to one paragraph each on Situation and Complication, which is enough for any reasonably informed audience.
2. **The buried lede.** Answers stated on page seven of a memo are not read. Executives skim openings and skip ahead to recommendations; if the recommendation is not in the opening, they make decisions on partial information. SCQA front-loads the Answer.
3. **The disputed premise.** Writers state Situations that are themselves contested ("our market position is weakening" — but is it?), which converts the body of the document into an argument about the premise rather than the recommendation. The Situation should be uncontested; the Complication is where novelty lives.

For consulting and executive communication, SCQA is the single most useful structural template — it works for memos, decks, emails, verbal updates, and full reports with only minor variation. Practiced writers internalize it as a default and reach for it without thinking.

## How To Use This Thinking Tool

```
|======|=================================================================================|
| Step |                                     Action                                      |
|======|=================================================================================|
|    1 | Identify the audience and what they already know / accept. The Situation must    |
|      | be drawn from inside this set.                                                   |
|    2 | Draft the Situation in one or two sentences. Test: would the audience nod and    |
|      | move on, or would they stop and contest? If they would contest, simplify until   |
|      | uncontested.                                                                     |
|    3 | Draft the Complication — what changed, what's new, what tension this creates.    |
|      | This is where the document's reason for existing lives.                          |
|    4 | Surface the Question the Complication forces. Often this is implicit; making it  |
|      | explicit ensures the Answer addresses what the audience actually needs.          |
|    5 | State the Answer directly. This is the document's main message — the             |
|      | recommendation, the finding, the call to action. Lead with it, defend below.    |
|    6 | Audit: does the Answer actually answer the Question? Does the Question follow    |
|      | from the Complication? Does the Complication disturb the Situation? Does the     |
|      | Situation match the audience's accepted reality?                                 |
|    7 | Rewrite if any link in the chain is weak. SCQA is a chain — one weak link        |
|      | undermines the rest.                                                             |
|    8 | Use the Answer as the apex of a Pyramid (see Minto Pyramid Principle entry):     |
|      | the body of the document supports the Answer in MECE branches below.             |
|======|=================================================================================|
```

## The Actual Thinking Tool

```
THE FOUR-PART OPENING

   SITUATION:    [What the audience already knows / accepts]
                 _______________________________________________

   COMPLICATION: [What changed / what tension this creates]
                 _______________________________________________

   QUESTION:     [What the complication forces the audience to ask]
                 _______________________________________________

   ANSWER:       [The document's main message]
                 _______________________________________________

   This sequence forms the introduction. The body of the document supports
   the Answer in pyramid form (see Minto Pyramid Principle).

THE THREE PATTERNS

   STANDARD (S → C → Q → A):
       Use when the audience needs lead-up. Default for most documents.
       Reads as: "Here's where we are, here's what changed, here's what
                  we now need to figure out, here's what we recommend."

   DIRECT (Q → A → S → C support):
       Use when the audience knows the context and wants the answer.
       Reads as: "Should we acquire X? Yes. Here's why now (S+C)."
       Common in time-pressured executive contexts.

   CONCERN-LEADING (C → S → Q → A):
       Use when the complication IS the point — crises, breaches, urgency.
       Reads as: "We've discovered a $50M shortfall in Q3. Background: we
                  had projected... The question now is... Our recommendation:..."
       The complication leads because attention to anything else is the
       wrong starting point.

   Diagnostic: which is right for THIS audience and THIS document?
   Default to Standard. Use Direct when explicitly asked for the answer
   first. Use Concern-Leading only for actual concerns.

THE SITUATION-DISPUTE TEST

   Read your draft Situation aloud as a sophisticated, possibly-skeptical
   audience member.

   If you would say: "yes, fine, go on" — the Situation is right.
   If you would say: "wait, hold on, that's not quite true" — REWRITE.

   Common failure: writers use the Situation to state the conclusion or
   the premise of their argument. The Situation should be banal — what
   nobody contests.

THE COMPLICATION-NOVELTY TEST

   The Complication should be the *new thing* — the recent event, the
   surfaced data, the changed condition that generates the document.

   If your Complication could have been written six months ago, it is
   not the actual Complication. Find what's new.

   Common failure: writers use the Complication to repeat a long-standing
   problem. That signals to the audience that this document does not have
   a fresh reason to exist, and they will deprioritize it.

THE QUESTION-EXPLICITNESS TEST

   The Question is often implicit in the Complication — but stating it
   explicitly forces the Answer to address what the audience needs.

   Test: write the Question as a literal question. If your Answer
   doesn't directly address it, either the Answer is wrong or the
   Question is wrong.

   Common failure: writers skip the Question, and the Answer ends up
   addressing a different question than the audience was asking.
   Symptoms: audience asks unrelated follow-ups, recommendations get
   disputed at the framing level.

THE ANSWER-DIRECTNESS TEST

   The Answer should be statable in one sentence.

   "We should acquire X for $Y million by Q3."
   "The right next step is to consolidate Programs A and B."
   "We should stop the integration and refund customers."

   If the Answer requires more than a sentence, you have not found the
   actual Answer — you've described the territory of the answer.
   Compress until one sentence works.

EXECUTIVE-EMAIL TEMPLATE (the most common use)

   Subject: [Answer in compressed form — verb-led if possible]

   Body:
       [Situation: 1-2 sentences, common ground]
       [Complication: 1-2 sentences, what changed]
       [Question / Answer: "The question is X. We recommend Y."]
       [Body: top-line supporting points, MECE if possible]

   This template works for status updates, proposals, escalations, and
   most one-screen executive emails. It is the SCQA shape compressed
   to email length.
```

> **Operational notes:** Four disciplines. (1) Pick the pattern (Standard / Direct / Concern-leading) before drafting. The default is Standard; the others are deliberate. Pattern-confusion in the introduction is a common cause of misfired memos. (2) The Situation must be uncontested. This is the highest-leverage edit in any SCQA draft — most failed openings fail because the Situation reaches for a conclusion instead of staying on common ground. (3) The Question should be explicit — write it as a literal question even if you don't include it in that form in the final draft. The literal question forces the Answer to actually answer it. (4) Pair SCQA with the Pyramid Principle: SCQA is the introduction; Pyramid is the body. Used together they produce executive documents that survive audience attention compression — the reader can stop after the introduction and still have the answer; reading further yields supporting depth. Used apart, SCQA is still useful as an introductory shape for any analytical writing.
