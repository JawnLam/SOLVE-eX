# Etak (Moving Island) Wayfinding Method

**One-line summary:** Carolinian/Polynesian wayfinding sub-method: divide a voyage into segments by reference to a non-visible 'moving island' whose imagined bearing changes through the journey.

**When to reach for it:** Studying or modeling sustained imaginative-spatial cognition without instruments — and understanding how navigation across vast featureless expanses can proceed via mentally-tracked reference frames.

## Purpose

Etak is a sub-technique within Pacific wayfinding traditions, most documented for Carolinian (Puluwat) navigators. The voyage is divided into segments; for each segment, a reference island (often non-visible, sometimes never directly seen during the trip) is held in imagination. The navigator tracks the reference island's apparent bearing against rising and setting star paths. Position-along-route is reckoned by how far the moving island has shifted. The cognitive payload: mental-position tracking sustained across days without instruments. Trains a distinctive imaginative-spatial cognitive capacity.

## How To Use

As an active method (limited application outside trained traditions, but illustrative for modeling): identify a navigation problem where instruments are unavailable or unreliable. Choose a reference point (not necessarily visible) whose location is known. Divide the journey into segments. For each segment, predict how the reference point's bearing should change given expected speed and heading. Track imagined bearing-shift to estimate progress. The deeper cognitive method generalizes: when explicit measurement is unavailable, anchor estimation to a stable mentally-held reference and track its apparent motion against known constants.
