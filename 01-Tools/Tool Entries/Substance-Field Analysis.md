# Substance-Field Analysis (Su-Field)

**One-line summary:** Model engineering systems as graphs of substances connected by fields (mechanical, thermal, electromagnetic, etc.) — diagnose problems and generate solutions via the 76 Standard Solutions.

**When to reach for it:** Engineering system analysis where the system can be modeled as substances acting on each other via fields; advanced TRIZ work in mature R&D organizations.

## Purpose

Su-Field is TRIZ's structural formalism. Any engineering system is modeled as two substances (S1 and S2) connected by a field (F). The full system is the triad S1-F-S2. Problems are categorized as missing-field, insufficient-field, harmful-field, or excessive-field. For each, the 76 Standard Solutions provide canonical resolution patterns. The formalism gives engineers a graph-theoretic vocabulary for invention.

## How To Use

1) Identify the substances and the field in the current system. 2) Diagnose: missing? insufficient? harmful? excessive? 3) Look up the relevant Standard Solutions for that diagnosis. 4) Apply: add a substance, change the field, introduce a third substance/field, etc. 5) Generate concrete redesigns.
