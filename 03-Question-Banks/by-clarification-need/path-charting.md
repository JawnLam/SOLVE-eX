# Path-Charting Questions

For use when both endpoints are Locked (or close to it) and the user is
charting routes between Origin and Destination. Spans Phases 3, 4, 5.

<!-- SECTION: PATH_CHARTING_OPENING_QUESTIONS -->
- What's between here and there?
- What's the first move you could make in the direction of this goal?
- If you had to lay this out as a sequence of steps, what's step one?
- What would have to be true for any path to work?
- What are the routes you've already considered?
- What's the route you'd take if you weren't worried about [obstacle the user mentioned]?
<!-- /SECTION -->

<!-- SECTION: PATH_CHARTING_CLARIFYING_QUESTIONS -->
- What information do you not yet have that you'd need to choose a path?
- Who else is on the path with you — by choice or by structure?
- What's the cost of the fastest path versus the cheapest path versus the lowest-risk path?
- What's the reversibility of each path you're considering?
- What's the path that lets you change your mind later, and what's the path that locks you in?
- What's a milestone that would tell you the path is working?
- What's a milestone that would tell you the path is failing?
- Who has walked a similar path? What did they learn?
- What's the path you'd take if money were no object? What's the path you'd take if time were no object?
- What's the smallest version of step one that still counts as progress?
- What's a part of the path you keep skipping over in your thinking, and why?
<!-- /SECTION -->

<!-- SECTION: PATH_CHARTING_STRESS_TEST_QUESTIONS -->
- If you took this path, what's the most likely way it would go wrong?
- Imagine it's a year from now and the path failed. What was the cause?
- Imagine it succeeded but worse than expected. What got compromised?
- What's the path you described, and what's the path you'd actually walk if you started tomorrow — same or different?
- Is there a path you're not considering because it feels socially unacceptable?
<!-- /SECTION -->

<!-- SECTION: PATH_CHARTING_REFRAMING_QUESTIONS -->
- What if the path is not linear — what's the smallest loop that gets you closer?
- What if the path requires waiting before acting? What does the waiting look like?
- What if you could only take one step and then had to pause for six months — which step?
- What's the path that someone in a totally different position than you would take?
- What's a path you'd recommend to a friend in your shoes, and is it the one you're taking?
<!-- /SECTION -->

<!-- SECTION: PATH_CHARTING_CLOSING_QUESTIONS -->
- Does the path we've sketched feel walkable, or is something missing?
- Ready to move from sketching paths to evaluating between them?
- What's the question we still need to answer before committing to a path?
<!-- /SECTION -->
