# Origin-Clarification Questions

For use when the user's **current state** (Origin) is Unclear or
Partially-clear. Bank applies regardless of phase.

<!-- SECTION: ORIGIN_CLARIFICATION_OPENING_QUESTIONS -->
- Tell me what's going on, in your own words, however it comes out.
- What's been happening for you with this lately?
- Walk me through what brought you here today.
- If you had to describe where you are right now in one sentence, what would it be?
- What's been on your mind that you haven't had a chance to say out loud yet?
- When you woke up this morning, what was the first thing that surfaced about this?
<!-- /SECTION -->

<!-- SECTION: ORIGIN_CLARIFICATION_CLARIFYING_QUESTIONS -->
- When did this start being a thing you had to think about?
- What were the conditions that led to this point — what was true before that isn't true now (or vice versa)?
- Who else is involved in the situation as you experience it right now?
- What's the part of where you are that's hardest to put into words?
- If we set aside what you want to happen, what is actually happening?
- What does "here" mean — physically, emotionally, professionally, relationally?
- What's something about your current situation that someone else might miss if they looked at it from outside?
- What are you doing day-to-day right now in relation to this?
- What's the constraint you're operating under that you wouldn't choose for yourself?
- What is going well in the current situation, even if it doesn't feel like much?
- What's the most recent moment that captures what your current state feels like?
<!-- /SECTION -->

<!-- SECTION: ORIGIN_CLARIFICATION_STRESS_TEST_QUESTIONS -->
- If a close friend asked you "what's happening?" right now, would you describe it the way you just did, or differently?
- Is there a part of how you described your current state that you're less sure about than it sounded?
- If you'd been asked this question a month ago, would the answer have been the same?
- Where in what you said are you reporting facts, and where are you reporting interpretations?
- What would have to be true for that description to be wrong?
<!-- /SECTION -->

<!-- SECTION: ORIGIN_CLARIFICATION_REFRAMING_QUESTIONS -->
- What's another way to describe the same situation, from a different angle?
- If we zoomed out to a year-long view, what would still be true about now?
- If we zoomed in to just today, what would be most prominent?
- How would you describe this if you weren't trying to be coherent — just listing what's there?
- What words would you avoid in describing this situation, and why?
<!-- /SECTION -->

<!-- SECTION: ORIGIN_CLARIFICATION_CLOSING_QUESTIONS -->
- Does the description we've landed on feel like it captures where you actually are?
- Anything missing from how you'd say it?
- Ready to use this as the starting point, or does it still need more shape?
<!-- /SECTION -->
