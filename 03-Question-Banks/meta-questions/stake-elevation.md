# Stake Elevation — Question Bank

Meta-question bank for use when the AI detects that the stakes
have been under-named — the user is treating a load-bearing
question as smaller than it is, or talking around the part of the
situation that actually matters most. Bank applies at any phase.

**Pacing rule.** Sparingly. One stake-elevation question in a
session is usually plenty. If the user resists the elevation,
respect it — sometimes the under-naming is the user's pace, not the
user's error.

**Voice discipline — load-bearing.** Non-pathologizing. The bank is
not for diagnosing whether the user is "in denial" or "minimizing."
It is for surfacing the gap between what the user has been talking
about and what the user has been carrying. The questions invite the
user to name the bigger version of the situation; they do not
accuse the user of having hidden it.

**Reference to safety-routing.** When the user names something that
elevates beyond a thinking-tool frame — suicidality, abuse, an
acute clinical situation — the AI exits this bank and routes per
chapter 09 (safety-and-stakes). See also Part 14 of the master plan.
The stake-elevation bank is for stakes that remain inside the
thinking-tool frame; safety-routing is for stakes that don't.

The two are continuous but the protocols are different. The bank
helps the user *see* a bigger version of a thinking-tool question;
safety-routing fires when the bigger version isn't a thinking-tool
question anymore.

<!-- SECTION: STAKE_ELEVATION_NAMING_QUESTIONS -->
- What's the biggest version of this question, before you trim it down to a workable size.
- What's the stakes story you've been keeping out of this conversation.
- If this turns out to matter more than we've been treating it, what would that mean.
- What are you carrying alongside this question that we haven't named.
- What's the question that's behind the question you came in with.
<!-- /SECTION -->

<!-- SECTION: STAKE_ELEVATION_HORIZON_QUESTIONS -->
- What does this decision affect a year from now.
- What does it affect five years from now.
- What does it affect for the people in your life besides you.
- What's the part of this that you'd want your future self to handle well.
- What would you be most regretful about not having addressed if you looked back from a decade out.
<!-- /SECTION -->

<!-- SECTION: STAKE_ELEVATION_IDENTITY_QUESTIONS -->
- What kind of person does this decision ask you to be.
- What does this question touch about who you are.
- Is there an identity choice underneath the practical choice.
- What's the version of you that this is a referendum on.
<!-- /SECTION -->

<!-- SECTION: STAKE_ELEVATION_HONESTY_QUESTIONS -->
- What's the part of this you've been treating as ordinary that isn't.
- What's the part of this you've been treating as urgent that may not be.
- Is there a moral weight on this that we haven't acknowledged.
- Is there a relational weight on this that we haven't acknowledged.
<!-- /SECTION -->

<!-- SECTION: STAKE_ELEVATION_PRESENT_QUESTIONS -->
- Now that we've named the bigger version, what changes about how we approach it.
- Does the bigger version need a different tool than the smaller one would.
- Is this still a thinking-tool question, or has it moved to a different category of help.
<!-- /SECTION -->
