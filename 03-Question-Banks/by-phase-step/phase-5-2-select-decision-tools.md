# Phase 5.2 — Select Decision Tools

For Step 5.2: choosing how to apply the criteria — which decision tool fits.

<!-- SECTION: PHASE_5_2_OPENING_QUESTIONS -->
- How do you want to weigh these options against the criteria?
- Are you looking for a quantitative method, qualitative, or both?
- Do you want to compare options head-to-head, or test each option in isolation?
- Is this a decision where ranking matters, or just yes/no?
- Is this a decision with one clear winner expected, or with several roughly-equivalent options?
- How much time do you want to spend on the evaluation?
<!-- /SECTION -->

<!-- SECTION: PHASE_5_2_CLARIFYING_QUESTIONS -->
- Have you considered a weighted decision matrix?
- Have you considered a decision tree with probabilities?
- Have you considered an expected-value calculation?
- Have you considered a pros-cons list with weighting?
- Have you considered the 10/10/10 frame (10 minutes, 10 months, 10 years)?
- Have you considered a regret-minimization frame?
- Have you considered a pre-mortem?
- Have you considered asking what a wise mentor would do?
- What tool feels like it fits the temperature of this decision?
- What tool have you used before that worked well for similar decisions?
<!-- /SECTION -->

<!-- SECTION: PHASE_5_2_STRESS_TEST_QUESTIONS -->
- Are you choosing a tool because it fits the decision, or because it confirms a tentative answer?
- What's the tool you'd avoid because it would surface something uncomfortable?
- Is the tool you're considering precise enough for this decision, or too precise (false rigor)?
- Are you using a quantitative tool to escape from a qualitative decision?
<!-- /SECTION -->

<!-- SECTION: PHASE_5_2_REFRAMING_QUESTIONS -->
- What if we used two different tools and compared?
- What if we made the decision tool deliberately rough and then checked the rough answer against intuition?
- What if we picked a tool from a different domain — military, design, medicine?
- What if the right tool here is "sit with it overnight and re-decide tomorrow"?
<!-- /SECTION -->

<!-- SECTION: PHASE_5_2_CLOSING_QUESTIONS -->
- Have we picked a tool (or set of tools) that fits the decision?
- Are you committed to letting the tool's output be informative, even if it contradicts intuition?
- Ready to actually run the evaluation?
<!-- /SECTION -->
